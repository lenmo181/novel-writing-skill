# 长篇模式手册（默认模式）

> 主文件的写作铁律、26项校验、黄金开篇、期待感体系全部适用，本文件只补充长篇特有的流程。

## 五种场景路由

| 场景 | 触发词 | 必读 | 特殊规则 |
|------|--------|------|---------|
| 开书 | 初始化项目/创建大纲 | 本手册+主文件全文 | 设定和大纲生成后**停在细纲交付等用户确认**，确认后才写正文 |
| 写指定章 | 写第X章 | 主文件+mind/档案 | 默认单章 |
| 日更续写 | 续写/直接续写 | 主文件+mind/档案 | 单轮≤3章 |
| 补纲/扩纲 | 补大纲/细化X卷 | 大纲四件套 | 只动纲不写正文 |
| 大修 | 重写第X章/大修 | 主文件+mind/档案+原章 | 先诊断再动刀，输出改前/改后对照 |

## 约束锁（写前必建，交付前必核）

动手写之前，把用户本次要求显式锁定为一行清单，完成后逐项打勾复核：

```
【约束锁】字数范围=XXXX-XXXX | 必发生=XXX | 禁止发生=XXX | 时间锚=XXX | 停笔点=XXX
```

- 用户没说的项填"无"，不许自己加戏再自己完成
- 交付前逐项核对，任何一项没兑现 → 改到兑现为止

## 卷纲取段

卷纲很长时不整读，只取当前写作单元的"闭包"：卷级常设设定 + 当前单元细纲 + 在用伏笔。依据 mind/章节目录.md 定位当前单元。`--check` 自查：主文件写作约束是否已下沉到本章细纲（没下沉=裸奔写作，先补纲）。

## 追读节奏自检（每卷中段跑一次）

- 每500-800字一个爽点/钩子是否守住？连续2章无爽点=掉追读
- 卷内小高潮分布：第1章(黄金开篇)、卷20%处(第一个中爽点)、卷50%(主线反转)、卷80%(最大危机)、卷末(大爽点+钩子)
- 感情线进度≤主线，每3-5章推进一次即可

## 情绪反查题材表（用户只说"想写XX感觉"时用）

| 用户要的情绪 | 题材方向 |
|-------------|---------|
| 爽感释放 | 打脸逆袭/战神归来/赘婿 |
| 意难平 | 感情拉扯/追妻火葬场/重生遗憾 |
| 紧张好奇 | 悬疑惊悚/规则怪谈 |
| 期待感 | 日常装逼/慢热种田/经营 |
| 治愈温暖 | 亲情成长/团宠/温馨种田 |
| 细思极恐 | 民俗诡异/心理悬疑 |

## 大修流程

1. 跑校验脚本 + 输出审稿卡，确认问题清单（用户点名的优先）
2. 标出可保留段（对话骨架/伏笔句/钩子）vs 必须重写段
3. 重写后新旧对照说明改了什么、为什么
4. 全流程重跑26项校验 + 更新 mind/ 档案（状态变了必须改快照）

## 平台适配速查

- **番茄**：免费阅读，下沉市场，开篇即冲突，爽点密度最高，本技能默认标准
- **起点**：男频hardcore，可容许2章内慢热但设定要硬，卷结构感强，追读看月票/追更
- **晋江**：女频精品向，感情线权重升，文笔容忍度高，开篇仍需钩子
- 用户点名其他平台时按其调性微调，不编造平台数据
