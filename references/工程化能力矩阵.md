## 发布最低闭环

init → write → check_chapter → continuity/project_health → full_review → repair_plan → snapshot → repair → check → full_review → release_check

任一失败 Gate 应停止交付；“告警”与“硬卡”必须按规则台账区分，不得为通过测试强行制造文本指标。


## v7.39 架构收敛

新增三条基础设施：

- `tools/canonical_parser.py`：统一角色状态快照基础解析。
- `repair_orchestrator.py --apply`：正文机械写入的显式授权门。
- `chapter_readiness.py --with-semantic`：第14-30项语义证据 Gate；配套 `schemas/chapter_semantic_review.schema.json`。

修复执行改为“队列明确命中章节 → 快照 → 最小范围修复 → 复检”，不再默认全书横扫。
