### 校验脚本使用（写完必跑）

```bash
python tools/check_chapter.py "<章节文件路径>"
```

- 在技能目录下运行；脚本全为纯标准库，路径用 `os.path` 处理（兼容中文路径）
- 退出码 0=通过；1=有硬伤**禁止交付**；2=输入错误（文件不存在/参数非法）；`[!]`警告逐条人工过目
- 输出含 **AI味指数（粗测0-10）**：≥6 必须按《去AI味手册》处理后再交付
- 摘要行誊入 mind/章节目录.md；`--min/--max` 调字数区间（短篇必用）
- `--quote chal|straight|any`（默认 chal）同时切引号违规检测与对话占比统计：短篇用 `straight`（半角双引号）、盐选可用 `any`（追加「」）
- `--dialog-min` 调对话占比下限（默认 15；短剧剧本可传 60）


### 朱雀AI文本线上检测（可选，v7.5）

`tools/zhuque_check.py` 调腾讯朱雀检测模型（EdgeOne Makers `@makers/zhuque-text`），对纯正文做**模型侧 AI 生成定量复核**，与本地 AI味指数互补：

```bash
# PowerShell：$env:ZHUQUE_API_KEY = "<你的Key>"；Bash：export ZHUQUE_API_KEY="<你的Key>"
python tools/zhuque_check.py "书稿/第001章_章节名.md" --allow-external
```

- 判定（v7.8 百分制）：**人类分 = 人工占比×100**；<80 退出码 1 **禁止交付**，80-89 警告须过目，**≥90 达标**；阈值真源=常量表·六
- 超标/警告自动列出 **AI 味最重分段**（`--segments N`），交《去AI味手册》8 Gate **定向改写**后重测，不整章重写
- 退出码：0=通过 / 1=超标禁止交付 / 2=无Key或文件错误 / 3=API或网络失败（**未检出≠超标，不触发闸门**）
- **未配置 Key 不阻塞交付**；建议开篇 3 章、高潮章、平台严打期逐章跑。结果解读与改写流程见《去AI味手册·朱雀线上检测》

### 墨尺本地检测（朱雀额度用尽的兜底，v7.7）

检测通路降级链：**朱雀（线上）→ 额度用尽/离线切墨尺（本地）→ check_chapter.py AI味指数（机械粗测，始终在）**。v7.8 起统一百分制**人类分**（朱雀=人工占比，墨尺=total×10），**≥90 达标；<80 禁止交付；80-89 警告过闸须逐段过目**。

```bash
python tools/mochi_setup.py                                  # 一键安装/自检（v7.42：定位→clone→路径持久化→起服送样章，装完免环境变量）
python tools/mochi_check.py "书稿/第001章_章节名.md"          # 单章
python tools/mochi_check.py --book "<项目根>" --only 3,7-12  # 全书/重测，报告落盘 mind/墨尺检测报告.md
```

- 判定（v7.8 百分制）：**人类分 = total×10**；≥90 达标；80-89 警告；**<80 退出码 1 禁止交付**（`--min 9/--floor 8` 可调，真源=常量表·六）
- 输出**短板指标**（40 项逐项分最低前 5）——节奏低→Gate D、句法低→Gate B、人味低→Gate E/H，定向改写后重测
- 全书报告与朱雀同构（轮次/较上轮/待修复清单/`--only` 合并）；重测上限 3 轮，连续两轮人类分涨幅<5 分移交人工
- 服务没起且未装墨尺 → 退出码 2 给指引（先跑 `python tools/mochi_setup.py`），**不阻塞交付**；手动兜底 `git clone` + 设 MOCHI_RULER_DIR 见《去AI味手册·墨尺本地检测》

**全书模式**（`朱雀全文检测/全书AI检测` 触发）：

```bash
python tools/zhuque_check.py --book "<项目根>"            # 扫 书稿/ 全部章节，报告落盘 mind/朱雀检测报告.md
python tools/zhuque_check.py --book "<项目根>" --only 3,7-12   # 修复后只重测指定章（省额度）
```

- 报告含：轮次 / 每章占比与较上轮变化 / 待修复清单（超标+警告章附重点分段）；重测自动合并上轮数据
- **修复循环协议**（检测→8 Gate 定向改写→--only 重测→达标）：见《去AI味手册·朱雀全书检测与修复循环》；单章重测上限 3 轮，连续两轮人类分涨幅<5 分移交人工（v7.25 起「较上轮」统一按人类分计，涨为正）
- 退出码（全书）：0=全部通过 / 1=存在超标章 / 3=存在检测失败章
