# 去AI味手册（8 Gate + 量化定档）

> 触发：`去AI味/这章太AI了/润色`。原则：**改味不改错、改说不改说啥**——不改变剧情、伏笔、人设事实。

## 8 Gate（按需选用，默认全开）

- **Gate A 禁用词**：主文件A级禁言词+B级限频+AI套话36词（脚本已硬卡，这里做语义级清理）
- **Gate B 句式套路**：主文件反AI啰嗦8条 + "不是X而是Y"高频滥用 + 排比连发
- **Gate C 情绪空转**：不推动任何变量的情绪独白（哭半天剧情没动=空转）
- **Gate D 节奏均匀**：句长/段长过度均匀 → 制造长短对比和单句成段重音
- **Gate E 对话腔调**：AI对话腔（对称/书面/每人说话方式没差异）→ 口头禅/打断/改口/省略
- **Gate F 结尾升华**：章末"这一夜注定无眠/他知道一切都变了"式上帝总结 → 换成落在动作/画面/悬念
- **Gate G 解释腔·上帝感·安排感**：作者跳出来解释（"原来这一切都是…" "命运弄人"）；巧合过度服务的痕迹；人物行为像提线木偶般刚好推进剧情
- **Gate H 自然度合同**（v7.3，治"文艺腔过载"）：见下节

## Gate H 自然度合同（细则）

**比喻使用规则**
- 默认不使用比喻；只有能传递普通描述无法表达的信息时才用
- 每800字≤1处明显比喻；连续三个段落内不得出现2处；同一情绪/动作/场景只用1次修辞
- 删除后句意不受影响的比喻→直接删；比喻必须符合视角人物的身份与认知（角色想不到的意象，旁白也不许用）
- 禁止连续使用同类意象（水、火、刀、深渊、野兽、黑暗、潮水、蛛网、琴弦等）

**AI式表达黑名单（脚本对多字符条目出警告，出现即按本Gate改写）**
空气仿佛凝固了 / 时间仿佛静止了 / 心中泛起涟漪 / 情绪如潮水般涌来 / 一根无形的弦绷紧了 / 像一把刀刺入心脏 / 像石子投入平静的湖面 / 黑暗将他吞没 / 理智的弦骤然断裂 / 某种说不清的情绪蔓延开来 / 他自己也没有意识到 / 有什么东西悄然发生了变化 / 这一刻，他终于明白 / 千言万语最终化作一句 / 沉默震耳欲聋 / 空气中弥漫着某种气息 / 眸色深了几分 / 指尖微微发白 / 心脏漏跳一拍 / 呼吸一滞 / "不容置疑/不容拒绝/不容反驳"重复强调句式——以及以上表达的近义改写。

**改法示范（抽象意象→具体行为）**
- ✗"空气仿佛凝固了，沉默像一道无形的墙横在两人之间。" → ✓"两人都没说话。桌上的水已经凉了，他仍握着杯子，没有喝。"
- ✗"愤怒如同火焰，在他的胸腔里燃烧。" → ✓"他把文件放回桌上，动作很轻。开口时，声音却比平时低了许多。"
- ✗"某种异样的情绪在她心底悄然蔓延。" → ✓"她本来准备离开，走到门口后却停了下来。"

**情绪描写优先级**：人物做出的决定 → 下意识动作 → 说话方式变化 → 刻意隐藏/回避的反应 → 简短明确的心理判断 → 最后才考虑比喻抒情。**一个情绪选一至两种表现方式即可**——已握紧拳头就不再解释"他十分愤怒"，已避开视线就不再补"她感到心虚"。

**动作不过度分解**：拿杯子不需要连续描写视线、手指、呼吸和杯壁温度；简单动作一步写完。对话结束后不必每次补神态、动作、心理。

**句子自然度**
- 长短句自然交替，不让每段都以抒情句收尾；不把普通信息拆成故作停顿的短句
- 不频繁用破折号、省略号、单句成段制造虚假张力（单句成段是节奏重音，不是默认排版）
- 允许人物说普通话、废话、半句话和不够漂亮的话（符合真实交流习惯即可）；允许叙述朴素直接
- 不重复解释已经说清楚的信息；优先准确的动词名词，少依赖形容词副词与抽象名词

**输出前内部自检（不展示过程）**：删多余比喻→删重复表达同一情绪的句子→空泛情绪换具体动作/选择→删故作深沉无信息量的句子→查"仿佛/似乎/微微/一丝/不由得/悄然/骤然"频次→查每段是否都在刻意营造文学感→查对话是否过于完整正确书面化→查普通场景是否被写得过分戏剧化。目标：**像作者在讲故事，不是在展示修辞技巧**。

## AI味量化定档（6指标，先测后改）

| 指标 | 轻度 | 中度 | 重度 |
|------|------|------|------|
| 禁用词密度/千字 | ≤5 | 6-15 | >15 |
| 连续排比段数 | ≤2 | 3-4 | ≥5 |
| 空转情绪句占比 | ≤10% | 10-25% | >25% |
| 对话标签密度（说道类占比） | ≤30% | 30-50% | >50% |
| 平均段落句数 | ≤3 | 3-5 | >5 |
| 重复描写密度/千字 | ≤1 | 2-3 | ≥4 |

- 综合定档=取最高档；中度指标≥3项按中度处理；核心场景（开篇/高潮/章尾）出现重复描写加权升1档
- 只许主观**下调**≤1档，不许上调
- 机器可测的部分以 `check_chapter.py` 输出为准（含AI味指数）

## 删除上限分级（防过度去味）

- 轻度 ≤15% / 中度 ≤25% / 重度 ≤35%（按原文字符数）
- 不得整段删除正文；删前必查该段是否含：伏笔/钩子/角色特征/情绪承接/因果锚点，含则改写不删
- 拿不准标 `[需复核]` 留给用户

## 三遍法（执行顺序）

1. **Pass 1 去泛化**：删套话、换具体（"深吸一口气"→直接删；"眼中闪过一丝"→"他垂下眼"；"嘴角勾起一抹"→"他嘴角一扯/乐了"；"缓缓开口"→"说"）
2. **Pass 2 去书面化**：书面词换口语（"顿时"→删或"一下子"；"随即"→"接着"）
3. **Pass 3 回自然感**：朗读测试——拗口的断句重排；补口头禅和不对称对话

## 收敛终止

- 同一段连续两轮无新改动 → 停
- 全文上限3轮；第3轮仍有≥10处改动 → 移交人工
- **嵌入式模式**：用户只要标注不要改 → 只出问题标记表不动文件

## 字数协议

输出报告必含：原文字符数/修订后字符数/净变化/是否超删除上限；正文改动后**必须重跑校验脚本**（去味后字数可能掉出区间，掉出则回补对话）。
