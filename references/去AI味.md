# 去AI味手册（8 Gate + 量化定档）

> 触发：`去AI味/这章太AI了/润色`。原则：**改味不改错、改说不改说啥**——不改变剧情、伏笔、人设事实。

## 8 Gate（按需选用，默认全开）

- **Gate A 禁用词**：主文件A级禁言词+B级限频+AI套话**34词**（脚本已硬卡，这里做语义级清理）
- **Gate B 句式套路**：主文件反AI啰嗦**10条** + "不是X而是Y"高频滥用 + 排比连发
- **Gate C 情绪空转**：不推动任何变量的情绪独白（哭半天剧情没动=空转）
- **Gate D 节奏均匀**：句长/段长过度均匀 → 制造长短对比和单句成段重音
- **Gate E 对话腔调**：AI对话腔（对称/书面/每人说话方式没差异）→ 口头禅/打断/改口/省略
- **Gate F 结尾升华**：章末"这一夜注定无眠/他知道一切都变了"式上帝总结 → 换成落在动作/画面/悬念
- **Gate G 解释腔·上帝感·安排感**：作者跳出来解释（"原来这一切都是…" "命运弄人"）；巧合过度服务的痕迹；人物行为像提线木偶般刚好推进剧情
- **Gate H 自然度合同**（v7.3，治"文艺腔过载"）：见下节

## Gate H 自然度合同（细则）

**比喻使用规则**
- 默认不使用比喻；只有能传递普通描述无法表达的信息时才用
- 每800字≤1处明显比喻；连续三个段落内不得出现2处；同一情绪/动作/场景只用1次修辞
- 删除后句意不受影响的比喻→直接删；比喻必须符合视角人物的身份与认知（角色想不到的意象，旁白也不许用）
- 禁止连续使用同类意象（水、火、刀、深渊、野兽、黑暗、潮水、蛛网、琴弦等）

**AI式表达黑名单（脚本对多字符条目出警告，出现即按本Gate改写）**
空气仿佛凝固了 / 时间仿佛静止了 / 心中泛起涟漪 / 情绪如潮水般涌来 / 一根无形的弦绷紧了 / 像一把刀刺入心脏 / 像石子投入平静的湖面 / 黑暗将他吞没 / 理智的弦骤然断裂 / 某种说不清的情绪蔓延开来 / 他自己也没有意识到 / 有什么东西悄然发生了变化 / 这一刻，他终于明白 / 千言万语最终化作一句 / 沉默震耳欲聋 / 空气中弥漫着某种气息 / 眸色深了几分 / 指尖微微发白 / 心脏漏跳一拍 / 呼吸一滞 / "不容置疑/不容拒绝/不容反驳"重复强调句式——以及以上表达的近义改写。

**改法示范（抽象意象→具体行为）**
- ✗"空气仿佛凝固了，沉默像一道无形的墙横在两人之间。" → ✓"两人都没说话。桌上的水已经凉了，他仍握着杯子，没有喝。"
- ✗"愤怒如同火焰，在他的胸腔里燃烧。" → ✓"他把文件放回桌上，动作很轻。开口时，声音却比平时低了许多。"
- ✗"某种异样的情绪在她心底悄然蔓延。" → ✓"她本来准备离开，走到门口后却停了下来。"

**情绪描写优先级**：人物做出的决定 → 下意识动作 → 说话方式变化 → 刻意隐藏/回避的反应 → 简短明确的心理判断 → 最后才考虑比喻抒情。**一个情绪选一至两种表现方式即可**——已握紧拳头就不再解释"他十分愤怒"，已避开视线就不再补"她感到心虚"。

**动作不过度分解**：拿杯子不需要连续描写视线、手指、呼吸和杯壁温度；简单动作一步写完。对话结束后不必每次补神态、动作、心理。

**句子自然度**
- 长短句自然交替，不让每段都以抒情句收尾；不把普通信息拆成故作停顿的短句
- 不频繁用破折号、省略号、单句成段制造虚假张力（单句成段是节奏重音，不是默认排版）
- 允许人物说普通话、废话、半句话和不够漂亮的话（符合真实交流习惯即可）；允许叙述朴素直接
- 不重复解释已经说清楚的信息；优先准确的动词名词，少依赖形容词副词与抽象名词

**输出前内部自检（不展示过程）**：删多余比喻→删重复表达同一情绪的句子→空泛情绪换具体动作/选择→删故作深沉无信息量的句子→查"仿佛/似乎/微微/一丝/不由得/悄然/骤然"频次→查每段是否都在刻意营造文学感→查对话是否过于完整正确书面化→查普通场景是否被写得过分戏剧化。目标：**像作者在讲故事，不是在展示修辞技巧**。

## AI味量化定档（6指标，先测后改）

| 指标 | 轻度 | 中度 | 重度 |
|------|------|------|------|
| 禁用词密度/千字 | ≤5 | 6-15 | >15 |
| 连续排比段数 | ≤2 | 3-4 | ≥5 |
| 空转情绪句占比 | ≤10% | 10-25% | >25% |
| 对话标签密度（说道类占比） | ≤30% | 30-50% | >50% |
| 平均段落句数 | ≤3 | 3-5 | >5 |
| 重复描写密度/千字 | ≤1 | 2-3 | ≥4 |

- 综合定档=取最高档；中度指标≥3项按中度处理；核心场景（开篇/高潮/章尾）出现重复描写加权升1档
- 只许主观**下调**≤1档，不许上调
- 机器可测的部分以 `check_chapter.py` 输出为准（含AI味指数）

## 朱雀线上检测（定量复核，v7.5）

本地 AI味指数是**结构粗测**；朱雀（腾讯 AIGC 检测模型，经 EdgeOne Makers 调用，`tools/zhuque_check.py`）给出**模型侧判定**。二者互补不互替：本地指标先过 → 朱雀定量复核 → 分段定位回 8 Gate。

**何时跑**（配置 Key 后，未配置则整体跳过不阻塞）：开篇前 3 章、高潮章、付费转化章；本地 AI味指数 ≥4 的章节；平台严打 AIGC 期间逐章跑。

**怎么跑**（Key 在 EdgeOne 控制台 → Makers → Models → API Key 创建，每月免费 50 万 token）：

```bash
set ZHUQUE_API_KEY=<你的Key>    # 或 --key 传入
python tools/zhuque_check.py "书稿/第001章_章节名.md"
```

**结果解读**（v7.8 起统一百分制：**人类分 = 人工占比×100 ≥90 才能交付**；阈值真源=常量表·六）：

| 人类分 | 结论 | 动作 |
|--------|------|------|
| ≥90 | 达标 | 直接交付 |
| 80-89 | 警告 | 脚本已列 AI 味最重分段 → 8 Gate 定向改写，不整章重写 |
| <80 | 硬伤（退出码 1） | **禁止交付**；按分段逐段改写后重测 |

**定向改写流程**：看 `--segments` 列出的重点分段（conf 越高越机器味）→ 只改这些段，套 8 Gate（重点 Gate B 句式 / D 节奏 / H 自然度合同）→ 删改前查伏笔/钩子/因果锚点（同「删除上限分级」）→ 重跑 `check_chapter.py`（字数掉出区间回补对话）→ 重跑朱雀。

**收敛终止**：连续两轮 ai_pct 下降不足 5 个百分点 → 停止改写移交人工；全文重测上限 3 轮。

**口径提醒**：朱雀网络/API 失败退出码 3 ≠ 超标，不触发交付闸门，排查后重跑即可。

## 墨尺本地检测（额度兜底，v7.7）

**检测通路降级链**：朱雀（线上模型判定，月额度 50 万 token）→ **额度用尽或离线时切墨尺**（本地读感统计，零额度零依赖）→ `check_chapter.py` AI味指数（机械粗测，始终在）。注意方向：朱雀 ai_pct **越低越好**，墨尺 total **越高越好**（0-10，越高越像真人），别搞反。

**准备（一次性）**：

```bash
git clone https://github.com/yycqyjq/mochi-ruler.git   # MIT，纯标准库，无需 pip
setx MOCHI_RULER_DIR <墨尺仓库路径>                      # 配好后脚本可自动启动服务
```

**怎么跑**（服务连 127.0.0.1:8765；没起且配了 MOCHI_RULER_DIR 会自动拉起）：

```bash
python tools/mochi_check.py "书稿/第001章_章节名.md"     # 单章
python tools/mochi_check.py --book "<项目根>"            # 全书，报告落盘 mind/墨尺检测报告.md
python tools/mochi_check.py --book "<项目根>" --only 3,7-12   # 修复后只重测未达标章
```

**结果解读**（v7.8 统一百分制：**人类分 = total×10 ≥90 才能交付**，与朱雀同一条线；阈值真源=常量表·六）：

| 人类分 | 结论 | 动作 |
|--------|------|------|
| ≥90 | 达标 | 直接交付 |
| 80-89 | 警告 | 过闸，按短板指标逐项过目 |
| <80 | 硬伤（退出码 1） | **禁止交付**；按最差指标项定向改写后重测 |

**定向改写**：输出列出**短板指标**（40 项逐项分最低的前 5 项，如节奏/句法/人味低分）——节奏低 → Gate D 制造长短对比；句法低 → Gate B 拆书面句式；人味低 → 对话加口头禅/打断/改口（Gate E）+ 情绪换动作（Gate H）。改完重跑 `check_chapter.py` 再重测墨尺。

**收敛终止**：全书重测上限 3 轮；某章连续两轮涨幅 **<0.5 分** → 移交人工。报告与朱雀报告同构（轮次/较上轮/待修复清单，`--only` 重测自动合并上轮数据）。

**口径提醒**：墨尺作者定位是"读感检测不是过检工具"——它治读感，不承诺通过外部平台；平台严打期仍建议在朱雀有额度时跑朱雀复核。服务不可用退出码 2 ≠ 不达标，不触发闸门。

## 朱雀全书检测与修复循环（v7.5）

触发：`朱雀全文检测/全书AI检测/批量朱雀`。全书跑一遍 → 按报告定向修复 → 只重测未达标章 → 循环到达标。

**第 1 步 全书检测**（扫 `<项目根>/书稿/`，章号识别口径与章节目录一致）：

```bash
python tools/zhuque_check.py --book "<项目根>"
```

报告落盘 `mind/朱雀检测报告.md`：轮次 + 每章 AI/疑似/人工占比 + **较上轮变化** + 待修复清单（超标/警告章附 AI 味最重分段，conf 越高越机器味）。退出码：0=全部通过 / 1=存在超标章 / 3=存在检测失败章。

**第 2 步 定向修复**（AI 执行，逐章推进，超标章优先、conf 高的分段先改）：

- 每章只改报告列出的重点分段，套 8 Gate（重点 Gate B 句式 / D 节奏 / H 自然度合同），不整章重写
- 守删除上限分级；删改前查伏笔/钩子/因果锚点，含则改写不删
- 每章改完**必须重跑** `check_chapter.py`（去味后字数掉出区间则回补对话）
- 摘要行与朱雀结果记入 `mind/章节目录.md`

**第 3 步 重测**（只测改过的章，省额度）：

```bash
python tools/zhuque_check.py --book "<项目根>" --only 3,7-12
```

报告自动合并：未重测的章沿用上轮数据，报告始终是全书最新视图；轮次自动 +1。

**循环与收敛**：

- 达标线：全书无超标章（人类分 ≥90）即可交付；目标线人类分 ≥95
- 每章重测上限 **3 轮**；连续两轮人类分涨幅 **<5 分** → 该章标记移交人工，跳过不再改
- 全部达标（或全部移交人工）后循环终止；修复期间不改章纲与档案设定，只动文字

## 删除上限分级（防过度去味）

- 轻度 ≤15% / 中度 ≤25% / 重度 ≤35%（按原文字符数）
- 不得整段删除正文；删前必查该段是否含：伏笔/钩子/角色特征/情绪承接/因果锚点，含则改写不删
- 拿不准标 `[需复核]` 留给用户

## 三遍法（执行顺序）

1. **Pass 1 去泛化**：删套话、换具体（"深吸一口气"→直接删；"眼中闪过一丝"→"他垂下眼"；"嘴角勾起一抹"→"他嘴角一扯/乐了"；"缓缓开口"→"说"）
2. **Pass 2 去书面化**：书面词换口语（"顿时"→删或"一下子"；"随即"→"接着"）
3. **Pass 3 回自然感**：朗读测试——拗口的断句重排；补口头禅和不对称对话

## 收敛终止

- 同一段连续两轮无新改动 → 停
- 全文上限3轮；第3轮仍有≥10处改动 → 移交人工
- **嵌入式模式**：用户只要标注不要改 → 只出问题标记表不动文件

## 字数协议

输出报告必含：原文字符数/修订后字符数/净变化/是否超删除上限；正文改动后**必须重跑校验脚本**（去味后字数可能掉出区间，掉出则回补对话）。
