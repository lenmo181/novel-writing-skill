# 封面手册（v7.8 执行协议 + 规格标准）

> 触发：`生成封面/做封面`。有 `$story-cover` 或 `$imagegen` 技能时优先调用它们执行，本手册是规格标准与验收闸门；都没有则按本手册提示词用可用图像工具生成。
> **交付物双通路**：有出图能力 → 出图 + 双层质检闭环；**无出图能力（无 Key / 无内置生图）→ 提示词即交付物**，落盘 + 全文展示给用户，用户拿去任意生图平台出图。
> 闭环（有图时）：出图 → 机械质检（`tools/cover_check.py`）→ AI 看图核验语义 4 项 → 不合格换构图重出，最多 3 轮。

## 执行协议（六步，全平台通用）

1. **信息收集**：书名 + 作者名（笔名）**缺任一必须问用户补全，不得编造或留空**；目标平台（默认番茄）；可选参考图/风格偏好
2. **平台定比例**：番茄=3:4 生成 `768x1024`（上传 600x800）；其他平台默认 2:3 生成 `1024x1536`（比例真源=常量表·七）
3. **组装提示词**：三层结构（下文）+ 题材字体表 + 构图方案，首次出 2-3 方案供选
4. **交付（双通路）**：
   - **通路 A 出图**（有 `$story-cover` / `$imagegen` / 生图 Key 任一）：`$story-cover` 设 `BOOK_DIR=<项目根>/封面/`；`$imagegen` 出图后移入同目录 → 走第 5 步质检
   - **通路 B 提示词交付**（无任何出图能力，**不是失败，是正常交付**）：
     1. 提示词落盘 `<项目根>/封面/封面_v1.prompt.txt`（头部标注方案名/比例/平台）
     2. **回复中全文展示提示词**（不要只说"已保存"），中英各一版（英文版出图效果更稳）
     3. 附一行使用指引："粘贴到 Midjourney / 即梦 / 豆包 / 可灵等任意生图工具，比例选 3:4（番茄）"
     4. 用户拿成图回来后 → 用 `cover_check.py` 质检 + AI 看图核验，不合格按第 3 步改提示词重出
5. **双层质检**（通路 A 出图后，或用户带图回来后）：
   - 机械：`python tools/cover_check.py "<项目根>/封面/封面_v1.png" --platform fanqie`（尺寸/比例/体积/提示词落盘纪律，退出码 0 才继续）
   - 语义（AI 看图核验）：① 书名笔名渲染无错字 ② 题材匹配 ③ 构图合理 ④ 书名笔名在中央 85% 安全区内
6. **导出上传尺寸**：平台有固定像素（番茄 600x800）时居中裁剪+缩放兜底（ImageMagick `--resize WxH^ -gravity center -extent` 或等效工具），不依赖出图尺寸

## 版本化落盘

- 命名：`封面/封面_v1.png` 自增不覆盖（v2、v3…）+ 同名 `.prompt.txt` 存提示词（+`.ref.txt` 存参考图说明）
- 每轮重出 = 新版本号；`cover_check.py --prompt-strict` 可把提示词缺失升级为硬伤
- 换构图方案（A/B/C）时在新版本 `.prompt.txt` 头部标注方案名

## 平台尺寸（关键坑）

- **番茄**：上传位 600×800，是 **3:4 不是 2:3** → 生成用 `768x1024`；比例不对，平台二次裁剪会切掉书名/笔名
- 起点/晋江/七猫等：默认 2:3 → 生成用 `1024x1536`
- 安全区：书名和作者名必须落在画面中央 85% 区域内（裁剪不吃字）

## 提示词三层结构（全英文效果更稳）

1. **文字层**：书名原文+作者名（要求文字渲染准确）
2. **风格层**：平台调性（番茄=高饱和强对比网感封面；起点=史诗感；晋江=唯美）
3. **画面层**：题材+构图方案

## 题材判定优先级

仙侠 > 西幻 > 古言 > 现言 > 都市 > 悬疑 > 科幻 > 历史 > 灵异 > 轻小说；零命中默认都市。

## 题材字体速查（书名/作者名分开配）

| 题材 | 书名字体方向 | 作者名字体方向 |
|------|-------------|---------------|
| 仙侠 | 金色毛笔书法+金属光泽 | 小号楷体白字 |
| 玄幻 | 立体金属字+闪电纹理 | 银色衬线小字 |
| 都市 | 现代粗黑体+霓虹描边 | 灰白无衬线 |
| 悬疑 | 破裂红字+阴影渗血感 | 暗红小字 |
| 民俗怪谈 | 斑驳旧字+纸人红衣元素 | 墨黑小字 |
| 甜宠 | 圆润粉字+爱心光斑 | 粉白手写体 |

作者名三要素齐全：字体+颜色+装饰元素。

## 三种构图方案（首次出2-3方案供选）

- **A 人物特写+场景**（通用）：主角面部/半身+标志性背景
- **B 全身像+动态**（玄幻/都市/西幻）：主角全身动作+能力特效
- **C 纯场景氛围**（悬疑/科幻/历史）：无人场景+悬念元素

## 重出与收敛

- 任一层质检不合格 → 换构图方案（或改提示词对应层）重出，版本号自增
- 上限 **3 轮**：3 轮仍有不合格项 → 停止重出，把各版本与不合格点列给用户人工挑选
- 交付版命名 `封面/封面_终版.png`（复制不移动，保留过程版本）
