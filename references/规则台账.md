# 规则台账（规则生命周期，v7.34）

> 触发：`规则台账 / 查规则来源 / 规则为什么是这样 / 废弃规则`；每轮热榜研究结束必更新本表。
> 定位：**规则层的唯一登记处**——凡进入 SKILL 核心规则、常量表、机械校验的写作规则，都必须在此登记生命周期；B 类题材卡仍归《热榜知识库》，不重复登记。
> 与证据等级的关系：本表记录「规则的一生」（来源→验证→现状→去向）；证据等级 S/A/B/C/D 是**数据质量维度**（见《热榜研究·研究证据等级》），A/B/C 分类是**验证广度维度**——三者合用：一条规则的级别 = 证据等级 + 验证广度。

## 一、字段与状态机

每条规则一行，字段：

| 字段 | 含义 |
|------|------|
| ID | RB-NNN，永不复用 |
| 规则 | 一句话规则本体（数值与常量表一致） |
| 来源 | 首次发现轮次/版本 |
| 验证 | 累计验证轮次×样本本数（题材数） |
| 级别 | 验证广度 A=跨题材≥3本 / B=题材≥2本 / C=单本 / D=推测 **+ 证据等级 S/A/B/C/D**（数据质量，v7.34） |
| 状态 | **候选→实验→稳定→修正→废弃** 五态 |
| 落点 | 当前落在哪里（常量表/SKILL/脚本/书格/仅知识库） |
| 执行工具 | 谁在执行这条规则（脚本/人工AI项）；**缺失=落点悬空，lint 报警** |
| 对应测试 | 哪个测试文件守护它；AI 语义项标「AI项」 |

**状态机纪律：**
- D 级**绝不**直接进入核心硬规则（先「候选」）；
- B 级升 A 级需 ≥3 本跨题材重复验证；升级当日同步常量表与脚本；
- 「修正」必须写明证据与旧表述（保留一行旧版本，防丢失演进脉络）；
- 「废弃」规则保留在表中（状态=废弃），写明推翻证据——**禁止静默删除**；
- 台账条目与常量表/SKILL 数值不一致 = 规则漂移，`lint_skill.py` 报警，以常量表为准确侧修改台账。

## 四、使用方式

1. **写作/审校时**：不必查台账——规则本体已在 SKILL/常量表/脚本里生效；台账回答「为什么」。
2. **热榜研究后**：按《热榜研究·六》输出轮次记录时，同步更新对应 RB 条目的验证计数与状态；新规则入「候选」。
3. **质疑规则时**：先查本表来源与反例，再走常量表「八、修改约定」改数值——**禁止只改台账不改落点**。
