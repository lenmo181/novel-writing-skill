# 升级验证测试集（v7.52）

每项都可在临时项目中人工执行；前 15 项由 `tests/test_v752_continuity_workflow.py` 自动覆盖。失败标准是工具未报问题、把 warning 当 error、或输出与来源事实不一致。

| ID | 输入条件 | 预期结果 | 失败标准 | 验证方法 |
|---|---|---|---|---|
| C01 | 相邻场景地点从室内改到城外，所有过渡字段为空 | `SCENE_TRANSITION_MISSING` | 场景检查通过或没有定位行号 | 自动测试 + `scene_continuity --json` |
| C02 | 新场景没有进入原因 | `SCENE_ANCHOR_MISSING` | 未指出进入原因缺失 | 自动测试 |
| C03 | 新场景没有承接事件 | `SCENE_ANCHOR_MISSING` | 未指出承接事件缺失 | 自动测试 |
| C04 | 在场人物列为空 | `SCENE_ANCHOR_MISSING` | 允许无角色场景直接交付 | 自动测试 |
| C05 | 视角从主角变反派且无边界说明 | `SCENE_TRANSITION_MISSING` | 视角跳转无告警 | 自动测试 |
| C06 | 场景编号 1、1 或 2、1 | `SCENE_ORDER` | 重复/倒序未拦截 | 自动测试 |
| C07 | 角色快照标记某人已亡，场景把他列为在场人物 | `SCENE_DEAD_ROLE` | 死亡角色无解释出现 | 自动测试 |
| C08 | 同一角色在“第1天10点”同时出现在两个地点 | `SCENE_DOUBLE_LOCATION` | 未报告同时间跨地点 | 自动测试 |
| C09 | 场景纲仍是旧八列表头 | `SCENE_SCHEMA_LEGACY` warning，默认不阻断 | 把兼容 warning 当成功事实或静默跳过 | 自动测试 |
| C10 | 章纲缺少目标/冲突，上一章存在 | 任务卡 `needs_input` 并列缺口 | 任务卡 `ready` 或自行编造目标 | 自动测试 |
| C11 | 上一章正文和回顾存在 | 任务卡包含上一章路径、尾部事实和来源 SHA-256 | 任务卡引用计划代替正文 | 自动测试 |

| C13 | 伏笔表有未回收条目 | 任务卡保留该条目，状态不改写 | 计划回收被当成已回收 | 自动测试 |
| C14 | 物品在两个角色快照中同时持有 | `grep_consistency.py` 报双持有人 | 只因场景检查通过就交付 | 现有连续性回归 + 人工回执 |
| C15 | 伤势、能力或时间线与前文冲突 | `grep_consistency.py`/`continuity_check.py` 报告，语义项要求引文 | 工具把冲突静默吞掉 | 现有连续性回归 + `chapter_readiness` |

## 语义补充验收

以下不能由标准库脚本可靠判定，必须在第14-30项审校中提供正文 `quote` 和 `offset`：角色提前知道秘密、人物关系无理由跳变、无铺垫反转、无效对话/注水、幽默破坏严肃场景、人物突然违背核心动机。没有独立语义审校，不得把机械 Gate 通过写成“小说质量合格”。
