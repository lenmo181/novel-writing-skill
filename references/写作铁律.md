## 🔴 核心写作规则（AI必读！每次写作必须执行！）

### 🚫 格式禁忌

严禁出现在小说正文中（脚本硬卡）：
1. 禁止 `>` 引用符号、Markdown 引用格式、代码块、表格
2. 禁止 YAML frontmatter
3. 禁止段内残留写作过程标记（如【第一段完成，当前累计：XXX字】）

### 🗣️ 对话铁律（最高优先级！）

**网文不是散文，是"演"不是"描"！一整章全是场景描述没有对话 = 水文 = 读者直接划走！**

- **对话占比硬卡区间 15-50%**（脚本：<15%=硬卡，15-25%=警告，25-50%=健康指导区，45-50%=偏高警告，>50%=对话剧硬卡；短剧剧本≥60%体裁不变）。**v7.19 热榜实证**：5榜5书16章全章 span口径（引号内字符）实测 10-49%——《我不是戏神》10-17%、说书体《我以狐仙镇百鬼》10-35%，悬疑/惊悚/第一人称体裁天然低对话；写作目标仍取 25-50%；注意别用"含引号段落全段"口径自测（会把动作叙述算进对话，虚高约20个百分点）
- **每章至少3次对话交换**；**每个场景至少1次对话交换**
- 对话必须**有冲突、有潜台词、有信息差**；每句要么推进剧情，要么揭示人物，要么埋伏笔
- 对话后必须有反应，但不能用大段描述吞掉对话节奏
- **所有对话用中文弯引号 `“”`**（短篇平台例外见手册）
- 禁止**对话三症状**：机械问答式对称 / 科普嘴讲设定 / 不分场合插科打诨（v7.40 起 check_chapter.py 对三症状出警告级机械线索：问答长度对称/长对话设定名词密集/玩梗密度，供 AI 语义复核取证）

**对话写作模板：** 模板A冲突揭露型（60%章节）：场景≤30字 → A质问 → B反击/装傻 → A抛证据 → B爆发/反转 → 动作≤20字收尾。模板B信息交换型（25%）：给信息 → 追问 → 补后果 → 做决定。模板C情绪爆发型（15%）：挑衅 → 克制 → 升级 → 短句爆发（≤5字+动作）。

**对话归位六式（v7.15 五式+v7.19 增⑥；实测番茄热榜5书：《凡骨》《我不是戏神》《我以狐仙镇百鬼》《夫人离婚后，军阀大佬一夜白头》《惹金枝》，全样本无一处"他说："）**：
- ①**裸引号+上下文轮替**（默认主力）：对答清晰时连续多句零标签，热榜常态是一整段对话无任何归位
- ②**动作归位段独立成段**："男子摆了摆手，一口答应下来。"（放引号前后皆可，段里是动作不是"说"）
- ③**名字+动作+道独立成段**："中年人向小男孩问道。"——唯一的合法道类形态，道字必须背着动作，独立成段或句号收尾
- ④**动作铺陈+冒号道引出下段**："中年男子见状，轻叹了口气，随即又咧嘴一笑道："（引号在下一段行首）
- ⑤**半直认**："发话的是老拓。""豆子答得飞快。"
- ⑥**名字直引式（v7.19）**：宁祯："我是怕打扰。"——角色名+冒号+对白独立成行，民国/女频热榜高频（民国榜首第10章一屏3次）；建议每章≤3处且不连续，防剧本感
- **禁光杆说引导（最高优先）**：「他说：」「他说道。"」「她轻声说，"…"」等**代词+光杆说/说类词紧贴引号**=AI指纹（热榜几乎绝迹），写出口就地替换为①-④；**后缀式「”他说。」同罪（v7.18）**——引号结束后缀「”他说。"她说。"她低声说。」与引导式同源泛滥（v7.17.1批量修复实证湘西诡闻107章209处），一并计入；「他/她说：」引导式+后缀式每章合计≤2容许/3-5警告/>5硬卡（v7.17升级），说道/道类合计每章≤5，禁连续3句同一模式

### 📏 字数铁律

**每章严格2000-2500字（纯正文=中文字符+中文标点，脚本硬卡），目标带 2000-2300**。v7.19 热榜实证：5榜5书40章官方字数，主流 2000-2300、中位≈2090，包络 1629-3119（1629=中段过渡章、3119=完结章）——写短写密，不注水

**三段式写作（过程结构）**：第一段700字（600-800，对话25-45%，≥2次交换，段尾小钩子）→ 第二段900字（800-1000，对话25-45%，≥3次交换，累计≥1500）→ 第三段600字（500-700，对话20-45%，**最后落在章末钩子上**）。每段写完输出`【第X段完成，当前累计：XXX字，对话约：XXX字】`——**此标记只出现在过程回复，不得写进章节文件**。

**与「智能分段」的关系**：三段式=写章过程结构；智能分段=发布前按10%/60%/20%/10%标广告位的后期工具。互不冲突。

## 🥇 黄金开篇铁律

**前三章任务表（推荐位生死线）：**

| 章 | 必须完成 |
|----|---------|
| 第1章 | 主角出场 + 异常事件/核心冲突亮相 + 金手指或悬念露头 |
| 第2章 | 金手指第一次小规模演示 + 近期目标确立 + 第一个爽点或打脸预告 |
| 第3章 | 第一个完整爽点闭环（打脸/收益），读者拿到第一次满足 |

**前300字手术标准**：第一屏必须出现**人物+异常**；第一句禁天气、景色、时间交代。

**机械闸门（v7.40）**：以上前三章条款由 `python tools/check_chapter.py <章节文件> --chapter-index N` 逐条硬卡（未传参时自动从标题行「第N章」推断）；禁开头8条、前300字人物+异常、前3段钩子信号任一命中即禁止交付。

**禁开头清单8条（出现即重写）**：天气景色开场 / 做梦梦醒 / "XX睁开眼"式醒来 / 照镜子自视外貌 / 大段回忆身世倒叙 / 世界观解说 / 无事件纯对话 / 日常流水账。

**开篇三句入戏（v7.16 热榜实证）**：正文前3段必须出现至少1个钩子信号——冲突动作 / 危机对话 / 异动悬念 / 倒计时面板；**时间戳+场景铺陈不得占前2段以上**（"大比前第八天，演场……"式起手连用=流水账感）；热榜惯用开场：拟声词砸场（"砰、砰砰……"）/ 裸引号喊话开场 / 危机倒计时开场 / 动作异动开场 / 第一人称谜团陈述（"我出生那天，在我家院子周围落下了十九道雷"）/ 女频短景速入人（景色仅1段且≤40字，第二段必须进人物+对话钩——《惹金枝》实证）。

**自检：删掉第一段，故事是否直接受损？不受损就删。**

**开头新鲜度（前3章专项）**：这段开头能整体搬进任意同类书吗？能=同质化，即使有钩子也是问题。

## 🪝 钩子三分法

1. **开篇钩**：前300字内让读者产生第一个问号
2. **章尾断章**：悬念/反转/情绪三型（见章末断点），落点=对白钩/画面钩/悬念面板/情绪句皆可（v7.19 放宽：《凡骨》章尾画面断章、《我不是戏神》【——我们在看着你】面板断章均热榜常态；对白优先，禁章尾总结腔不变）
3. **付费节点钩**：全书最强断点优先布置在20%-30%处（付费墙前最后一章），断点前后剧情点密度必须递增

## 🧬 钩子载体DNA 与叙事边界

**每章钩子必须登记一个语义指纹**，形如 `主角-发现-密信`，写在章纲/章节目录的钩子列。指纹让"这章的钩子"变成一个可核验的对象，而不是一句写在结尾的话。

**五槽指纹（v7.33，最低三槽）**：`载体-动作-对象-信息性质-后果`——前三是必填（旧口径），后两槽推荐填写，专治"钩子写了个东西但没有信息量"：
- 示例三槽：`主角-发现-密信`
- 示例五槽：`主角-发现-密信-敌国密文-牵出灭门旧案`（性质=这封信是新信息还是身份揭示；后果=读者此刻确信会发生什么）
- 反例：`主角-看到-一封信`（对象空泛、无性质无后果——读者没有"必须翻页"的理由）

**交付前两步核验（缺一不可）：**
1. **指纹一致**：正文结尾钩子与**章节名**的语义 = 章纲登记的指纹（载体、动作、对象对得上，五槽时性质/后果不跑偏；章名三对齐 v7.10——章名是钩子的预告片，不是内容概括）
2. **意图一致**：本章钩子的核心情绪 / 指向 / 潜台词未跑偏（登记的"发现"变成了"被吓到"= 跑偏）

**钩子归属三铁律：**
1. **起段只回收上一章的钩子**（不新开）
2. **合段（结尾）只生成本章的钩子**（不顺手埋下章的新线）
3. 钩子**只描述"已形成的状态"**，禁用"将要发生"的未来时态（写"门开了，里面坐着个人"，不写"下一秒他将面对真正的恐怖"）

**跨章防提前消耗（v7.33）**：下一章不得提前兑现本章钩子的"后果槽"（登记了"牵出灭门旧案"，下一章必须真查案，不许绕开）；同一指纹连续两章登记=一个钩子反复使用，返修换钩。

**不通过的处理**：重构思 → 重验。**连续 3 次不通过 → 报「本章钩子越界」并停下等指令**（不硬写、不擅改大纲）。

**章节开头注明**：本章正文受《平台审核红线》约束（涉政/未成年/暴力过程细节等一律按主文件红线执行）。

## 🎣 期待感体系

爽点=即时兑现；期待感=延迟兑现，真正的翻页引擎。**每章必须让以下至少一条被制造或被推进：**

1. **打脸预告**：读者知道主角有底牌，场内配角不知道→等爆发
2. **身份悬念**：真实身份/来历/目的吊着读者
3. **目标牵引**：明确近期目标+差距感（夺回东西/三日后比武/差一颗丹药）
4. **危机倒计时**：明确的时间/资源压力

**信息差三层管理**：读者知道/主角知道/配角知道。打脸爽感=信息差套利。写前明确三层知情范围，写完更新快照"知情"字段。

## 💥 爽感闭环 + 打脸四拍

**三段式爽感闭环**：铺垫压制（主角被踩/被质疑，读者憋屈）→ 爆发兑现（亮牌翻盘，落点是动作或对话）→ 反馈余韵（围观震惊/收益落袋/地位变化，把爽感钉死）

**打脸四拍**：挑衅施压（反派嚣张到位）→ 隐忍蓄势（主角不动声色，读者知底牌）→ 亮牌碾压（实力揭晓干脆利落，不磨叽）→ 围观震惊（旁观者反应层层递进收尾）

## ⚙️ 金手指设计四原则

有**门槛**（不是无限白嫖）/ 有**代价**（用了要付出）/ 可**成长**（随主线升级）/ 可**可视化**（面板/系统/等级让读者看见进度）。系统流/签到流/空间流/模拟器流均适用。

## 🎥 视角纪律

- 默认**第三人称、单主角限知视角**（短篇默认第一人称），用户指定除外
- 用户指定“必要时少量切换角色视角”时才允许切换：以场景分隔或明确空行作为切换边界，每个场景内保持单一限知，不把配角内心和主角未知事实同时写成上帝视角
- 切换应服务信息差、并行危机或章末钩子；主视角仍以主角为主，避免连续多次跳转。禁上帝剧透（“他不知道的是”全章≤1次且服务章末钩子）
- 多视角戏空行分场，每场内单视角；没有明确必要性时沿用主角视角，不主动扩展为群像

**群像/多线合法剧本（v7.40）**：「一章内禁止切换视角」默认铁律不变；确需多线群像（权游式）时，必须在 `mind/书格.md` 声明 `群像模式`，并遵守：①视角切换只发生在**章边界**，章内仍单视角；②每条线有唯一视角人物与线帽（如「北境线」「京城线」）；③并行线索 ≤3 条，要开新线先合并旧线；④每条线独立执行钩子三铁律，跨线信息差登记进信息差矩阵；⑤检测姿态：声明群像后章边界换线视为合法，未声明的章内多线切换仍按第26项视角漂移硬卡。

## 🎭 Show don't tell

- **禁止直贴情绪标签**："他很愤怒"→写行为生理反应（愤怒→杯子放下时重了那么一点；紧张→数到第三次楼下的脚步声；悲伤→把那双没人用的筷子也摆了上去）
- 情绪词只允许出现在对话里；品质/能力不直接断言，用旁人反应和事实展示
- 脚本抓"感到/非常+情绪词"警告 + AI味指数辅助

**情绪表现优先级（从先到后）**：人物做出的决定 → 下意识动作 → 说话方式变化 → 刻意回避的反应 → 简短心理判断 →（最后才是）比喻抒情。**一个情绪最多用2种表现方式**——已握紧拳头就别再补"他十分愤怒"。

**比喻限额**：默认不用比喻；每800字最多1处明显比喻，连续三段不得出现2处；同一情绪/场景只用1次修辞；删掉比喻句意不受影响→删；意象类别（水/火/刀/深渊/野兽/潮水/蛛网/琴弦）不得连续使用；比喻必须落在视角人物的认知范围内。脚本对比喻词超限额出警告（细则见去AI味手册 Gate H）。

## 🫀 人味与失控感（治深层AI味）

- 加**非理性行为**：人在情绪上头时会做"不划算"的事
- **情绪不完整**：不要每次哭完就恢复、吵完就和好——留毛边
- **不闭环**：不是每个伏笔当章都收，不是每段都总结意义
- 目标：像"情绪记录"，不像"说明书"

## 🎬 剧情推进力铁律（反打圈，AI必读！）

**不可逆原则：每章结束时，故事状态必须相对章首发生不可逆变化。写完自问——"看完这章，哪件事回不去了？"答不出 = 本章是水文，重写，不许交付。**

### 推进四问（每章自检，普通章命中 ≥2 项；主线/峰值章 ≥3 项）

| 问 | 校验内容 | 示例 |
|----|---------|------|
| 新信息 | 揭示了此前未知的信息（谜底碎片/身世/规则/内幕） | 密信内容揭晓一半 |
| 新状态 | 某角色/关系/资源/位置发生不可逆改变 | 断臂/结盟反目/离开新手村 |
| 新目标 | 章末主角的下一步相对章首发生位移 | 从"筹钱"变成"复仇" |
| 新代价 | 本章付出可见代价（消耗/损失/承诺/落下把柄） | 灵石耗尽/欠下人情/暴露行踪 |

### 打圈黑名单（命中任一 = 本章返修）

- **矛盾原地踏步**：同一核心矛盾连续 ≥2 章既未推进也未升级（重复呈现同一冲突现场）
- **模式不变奏**：同一冲突模式（被质疑→打脸/遇袭→反杀/误会→解释）连用 ≥3 次无变奏
- **状态回归原点**：章末人物位置/资源/关系与章首相同，且无代价补偿
- **对话绕圈**：同一话题在章内 ≥2 轮往返（A 说服 B→B 不信→A 再说服）
- **情绪空转**：同一种情绪反复渲染但不推动任何决策（与 Gate C 同源）

### 打圈解法：变量注入（四选一，插入即可破圈）

新信息（爆一条内幕）/ 新人物（搅局者入场）/ 新限制（deadline/新规则/追踪者逼近）/ 时间跳跃（直接跳过僵持期，写僵持的结果）

## 📱 网文排版

- **单段 >140 字=硬卡（文字墙），100-140=警告**（真源=常量表·二与 `tools/config.py`；说书体/古言/官场罪案等长段体裁经 `--wall 200` 书格覆盖，v7.35 前本行曾写 160 系口径漂移已修正）；段落=手机端1-3行
- **单句成段≥3处/章**制造节奏重音（打脸台词/反转句/宣言）
- 对话独立成段；转折/新场景空行分场

## 🧱 场景单元结构 + 落差公式

**每个场景 = 目标 → 阻碍 → 转折**：视角人物想要什么 → 什么拦住 → 结果≠预期。场景纲按此三字段写。

**落差公式**：制造冲突=先抬预期再砸落差（"他以为稳了"→反转）；制造爽感=先压低主角再抬升兑现（"被踩到泥里"→当众翻盘）。三步：抬预期（压主角）→ 砸落差（抬升）→ 兑现情绪，**落点必须是动作或对话**。

## 🧵 作者记忆系统

跨会话记住作者的写作习惯与要求。落在 `mind/作者记忆.md`，四类记录：

| 类型 | 处理 |
|------|------|
| 一次性要求 | 只执行不记录（"这章别写雨戏"） |
| 小说事实 | 写进本书设定（"女主妹妹叫XX"） |
| 推断偏好 | 先记"待确认"，下次复现才转正（"用户似乎不爱写环境描写"） |
| 与旧记忆冲突 | 显式 replace，保留一行旧记录标注日期 |

**回执机制**：用户说"记住：XXX"→ 执行后必须输出 `✅ 已记住（类型：XX）`，没输出回执=没记住。

## ⛓️ 设定优先级链（材料打架时按此裁决）

写作输入多源（指令/设定/大纲/前文/回顾），发生冲突时**从高到低**：

**本次用户指令 > 剧情走向锁定 > 角色卡核心设定 > 世界观三根高压线 > 最近章节正文 > 较早章节回顾 > AI自行推断**

- 不得为戏剧效果擅自推翻已定设定；用户临时想法与世界观冲突时**先上报冲突并给安全替代写法**，不得静默改设定
- 材料自相矛盾（如两份档案打架）→ 上报用户裁定；等不到回复时选对已有剧情影响最小的方案并**显著标注**
- 金手指/能力边界冲突一律按"更严"的那版执行

## 🎏 题材例外优先原则（v7.35，规则冲突时按此裁决）

写作参数按**四层级从宽到严**裁决，下层可覆盖上层，**底线不可覆盖**：

**已确认合法的题材/功能例外**（有热榜证据支撑，检测时降级为注记而非告警）：

| 例外 | 依据 | 检测姿态 |
|------|------|---------|
| 悬疑/说书/经营囤货/无CP升级流低对话（span 可低至 0-23%） | RB-005/RB-016 | `--dialog-min` 书格钉下限，不按默认 15 误报 |

## 🧾 扩写权限白名单（写章自由度的边界）

**可以自由补充**：场景细节 / 人物动作 / 对话 / 心理活动 / 情绪张力 / 合理过渡 / 与主线相关的小伏笔

## 📋 标准审稿卡 + 追读诊断

**单章快评（`续写并审稿` 输出）：**

```
【审稿卡·第X章】
期待感   X/5（推进的期待线：打脸预告/身份悬念/目标牵引/危机倒计时）
爽点兑现 X/5（类型+落点是否为动作/对话）
对话质量 X/5（冲突/潜台词/非对称/提示语多样性）
节奏密度 X/5（快慢切换/单句成段/无水文）
人设一致 X/5（口头禅/怪癖/决策逻辑）
脚本结果：<check_chapter.py 摘要行 + AI味指数>
最伤的3个问题：1… 2… 3…
修复建议：…（或"已当场修复"）
```

**审稿闭环（审稿不是终点，是修复入口——不达标不算完章）**：出卡即闭环，卡上的问题必须当场处置，禁止只出卡不修就落断点。触发修复的红线：脚本任一硬项 ✗／AI味指数 ≥6／朱雀人类分 <90（配 Key 时；额度用尽切墨尺同线）／总分 ≤15/25。闭环动作：按「最伤的3个问题」定向改写（8 Gate，只动病灶段）→ 复测（`check_chapter.py` 必重跑；朱雀 `--only` 单章重测）→ 达标才更新断点记录，本章才算结束。**峰值保留**：每轮改写前备份当前版本，重测人类分低于历史最高即回滚该轮、换 Gate 再试（防越改越差，报告只记峰值）。**终止与移交**：单章重测上限 3 轮，或连续两轮涨幅 <5 分 → 停手，断点记录明标「第X章未达标，移交人工（附峰值版本+残留问题）」——不许静默当完成，也不许卡死一章不往下写。总分 ≤15/25 同走此闭环（当场重写病灶后复测）。**深度体检**（`诊断第X章`）：按《审校手册》追读诊断六维（钩子/爽点/伏笔/人设/节奏/人味，各1-5分，总分≤18/30建议返修）+ 输出"读者最可能划走的三段"。

## 📛 书名与简介

**书名四式**（≤12字优先，一次10个候选标注式别）：反差式（捡个小娇夫是千年尸）/ 金手指直给式（签到十年，我无敌了）/ 悬念式（那晚给我守灵的人不是我爸）/ 情绪共鸣式（重生后我把亏欠女儿的还回来）

**角色起名**：贴时代背景+有记忆点+易读易记；专治"叶辰/苏念"式烂大街名（先验证不撞大热书主角名）。

**简介公式（80-150字）**：第一句身份反差 → 第二句金手指/核心冲突 → 第三句钩子断言或问句。禁：剧透结局、世界观术语堆砌、"且看…"套话。

## 📛 章节名规范（v7.10，平台风格）

> 章节名是目录页的「一秒钩子」——读者划走前扫到的就是它。与书名四式同源，按本章钩子起名，**禁止空泛总结题**。数值真源=常量表·三B。

**章名五式**（2-12字，一次给3个候选选1）：
- **悬念反常式**：把本章最反常的一件事戳破——「扫地三年，面板动了」
- **金手指直给式**：能力/收获直接亮——「一帚扫出剑意来」
- **冲突预告式**：摊牌/对峙/危机上桌——「除名令：月底滚蛋」
- **名台词式**：章内最狠一句台词直接做题——「地要扫，架要打」
- **双段预告式（v7.19）**：「场景/物件，事件」——《凡骨》全书惯用（「风雪夜，小太平叩门求炭」「病榻前，得爷爷临终赠宝」），10-12字带逗号，场景定调+事件预告

**章名三对齐（第28项钩子DNA一并核验）**：章名预告 = 章纲钩子指纹 = 正文章末钩子，三者同源。章名不是内容概括，是钩子预告片。

**禁用黑名单**：
- 空泛总结题：开端 / 开始 / 新的开始 / 初入XX / XX前夕 / 风波又起 / 暗流涌动 / 尘埃落定（零信息量；前8个全等命中=脚本硬伤，其余归 AI 语义）
- 纯名词题：单个人名/地名/物品名直接做题（「宗门」「刘管事」）
- 剧透题：把本章结果说破（「陈砚夺得头名」）——预告冲突可以，剧透结果不行
- 邻章同构：完全同构句式连续两章禁；同一开头词**系列式**（如《凡骨》「转因果，」「同灭咒，」连用2-4章）≤3章且后半句必须换——系列式是热榜合法的小弧线标记（v7.19 放宽）

**口径**：正文标题行 `第N章 标题`（阿拉伯数字）；文件名仍用 `第XXX章_标题.md`（三位序号保排序，gen_index.py 兼容）；命名时机=**写完正文、按实际章末钩子定名再落盘**（章纲可预起，以正文为准回填）；终章可用「大结局（全书完）」，不受黑名单限制。

- **小爽点**每1-3章 / **中爽点**每10-20章 / **大爽点**每卷一个

- 卷内节奏：第1章黄金开篇 → 20%处第一个中爽点 → 50%主线反转 → 80%最大危机 → 卷末大爽点+钩子

## ⚖️ 节奏与结构量化

> 细则与算例见 `references/节奏与结构.md`；数值真源见 `references/常量表.md`；算值用 `tools/conflict_score.py`。

### 冲突值（事件量级刻度）

```
冲突值 = 基础分 1 + Σ(权重 × 触发次数)
```

| 因子 | 权重 |
|------|------|
| 核心角色状态根本性改变 | +8 |
| Tier-1 战略级伏笔回收或埋设 | +8 |
| Tier-2 战役级伏笔回收或埋设 | +5 |
| 破格事件 | +5 |
| 重要实体（组织/物品）状态改变 | +3 |
| 核心角色参与（每位） | +2 |

**星级映射**：<5 ★☆☆☆☆ 日常｜5≤分<8 ★★☆☆☆ 推进｜8≤分<12 ★★★☆☆ 节点｜12≤分<16 ★★★★☆ **峰值**｜≥16 ★★★★★ 核心峰值。

**护栏（硬性）**：冲突值**仅用于事后标注与体检**；**严禁为提分而新增死亡 / 暴力 / 黑化事件**——日常章分值低不是缺陷。一切事件仍受《平台审核红线》约束。

**刻度说明**：**冲突值 = 事件量级刻度**（世界状态变了多少）；**爽点强度 = 读者情绪刻度**（读者爽到多少）。二者**不可互推、不可互替**：惨胜可以很高分却毫无爽感；一次当众打脸可以很低分却爽到极点。

### 章节节奏类型（枚举白名单，章纲标注）

**主线 / 峰值 / 缓冲-对话 / 缓冲-线索 / 缓冲-代价 / 校准**——六种，不得自造。写正文前据类型决定渲染重心（峰值章压缩心理与对话；缓冲-代价章聚焦代价具象）。

**缓冲章三型职责：**

| 类型 | 职责 | 硬要求 |
|------|------|--------|
| 缓冲-对话 | 关系演变 + 潜台词 | 删掉对话则剧情受损，否则算水文 |
| 缓冲-线索 | 伏笔与信息推进 | **单章揭示信息不超过该线总量的 30%** |
| 缓冲-代价 | 清算前文增益的代价 | **须在增益出现后 1-5 章内兑现** |

**缓冲章 ≠ 无爽点章**：硬下限——**任意连续 2 章必须有至少 1 个爽点或明显期待线推进**。缓冲比为目标**软指标**（基准 25% = 20% 可用缓冲 + 5% 校准），仅体检提示，**不熔断**。

**峰值禁区**：冲突值 ≥ ★★★★☆（分值 ≥12，峰值及以上）的章，其**前后各 2 章内不排「缓冲-对话」**。

**宏观节奏**：起承转合 **20:30:30:20**，**以卷为单位**（不是单章字数比例）。卷内里程碑 **20% 中爽点 / 50% 主线反转 / 80% 最大危机**——与上文「爽点黄金节奏」是**同一套里程碑的两种表述**：那条给定性位置，本条给定量校验（20% 处冲突值应达 ★★★☆☆ 以上，80% 处应达 ★★★★☆ 以上）。

**破格配额**：每卷破格事件 **≤3 次**；破格**不得突破角色核心烙印**（核心驱动力 / 根本缺陷 / 绝对红线）。

**信息与伏笔**：单章信息解密 **≤30%**；伏笔 Tier 分级 **T1 战略 / T2 战役 / T3 战术**，沉睡阈值 **T3 15-20 章 / T2 30-40 章 / T1 卷末审计**；核心回收率 ≥80%、跨卷回收率 ≥60%（均为软目标，由体检跟踪）。

### 章纲/章节目录字段（v7.51）

- 长篇章节目录必须有 **「卷号」列**，列序为 `章号 | 卷号 | 标题 | 字数 | 节奏类型 | 校验结果 | 完成日期`；番茄默认不允许新章脱离卷纲。
- 章纲新增 **1 列「节奏类型」**（取值同上六种）；**「冲突值」为可选列**（需要时由 `tools/conflict_score.py` 生成）
- **章节名（v7.10）**：章纲钩子列可顺带预起章名候选，正文写完后按实际章末钩子定名落盘并回填章节目录（标题列），以正文为准
- **保留「章末钩子类型」列并兼记语义指纹**（形如 `主角-发现-密信`）
- 章节目录列序：`章号 | 卷号 | 标题 | 字数 | 节奏类型 | 校验结果 | 完成日期`（由 `tools/gen_index.py` 维护，卷号可按卷纲起止章范围初步推断，读旧表合并、不覆盖既有值）

## 🎨 引号配置

**长篇（默认）**：对话中文弯引号 `“”`（`\u201c\u201d`），独白 `‘’` → 脚本 `--quote chal`（默认值，无需传参）。

**短篇**：默认半角双引号 `" "` → 脚本 `--quote straight`；**盐选可「」** → 脚本 `--quote any`（弯引号 + 半角双引号 + 「」都计入对话，不判引号违规）。

`--quote` **同时**驱动「引号违规检测」与「对话占比统计」，两处口径永远一致——改口径只传这一个参数，不要再手工改脚本里的正则。
