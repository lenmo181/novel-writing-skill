# 技能目录结构

> v7.44 从 SKILL.md 外置。本表是 `doctor.py` 目录树登记完整性的真源，新增文件必须登记。
>
> **豁免目录（不参与登记比对）**：`packaging/` 与 `assets/` 不随技能包分发
> （上架包构建已排除），故 doctor 对**登记侧与磁盘侧同时豁免**——这两类目录下的
> 文件既不会被要求登记，也不会成为「登记但不存在」的幽灵条目。
> `packaging/` 的完整构成见文末「附」节（不进本树，人读用）。

## 附：`packaging/` 分发封装（**不随技能包分发，免登记**）

多形态分发的封装目录。构建上架包时整体排除（`build_market_zip.py` 的 `EXCLUDE_DIRS`），
因此不参与上面的目录树登记比对，仅在此以人读方式列出。

```

│   ├── server.json           # MCP Registry 清单（official schema 2025-09-29）
│   └── README.md             # 宿主接入说明（Claude Code / Desktop、Cursor、WorkBuddy…）

    ├── manifest.yaml         # 插件清单
```

**三态口径统一**：`doctor.py` v7.46 起把豁免判据同时作用于登记侧与磁盘侧，
使「仓库 / 上架包 / wheel」三种形态下目录树检查结果一致（均为 91/91）。
