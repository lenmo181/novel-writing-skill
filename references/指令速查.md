# 常用指令速查

> v7.44 从 SKILL.md 外置；SKILL.md 只留路由表与指针。

| 指令                              | 功能                                                                                         |
| ------------------------------- | ------------------------------------------------------------------------------------------ |
| `初始化项目`                         | 按 `templates/项目模板.md` 建目录+模板文件                                                             |
| `写第X章` / `续写` / `直接续写` / `一键生成` | 长篇写作（30项校验+更新档案）                                                                           |
| `续写并审稿`                         | 写完自动出标准审稿卡；**不达标当场修复→复测，达标才落断点（审稿闭环）**                                                     |
| `写短篇《X》`                        | 短篇四阶段流程（默认第一人称，8000-20000字）                                                                |
| `写短剧剧本` / `小说改剧本`               | 竖屏短剧/漫剧剧本（每集强卡点）                                                                           |
| `扫榜` / `选题`                     | 市场调研+选题决策                                                                                  |
| `拆书《X》`                         | 爆款拆解，写法档案可复用                                                                               |
| `导入《X》`                         | 旧稿逆向接入，从断点续写                                                                               |
| `导出txt` / `作家助手导入`              | 合并 书稿/ 为单文件 txt（默认全本，可 `--range 1-50` 选章）                                                  |
| `初始化续写`                         | 旧项目档案结构升级：映射生成 mind/ 七档案，旧追踪冻结为只读                                                          |
| `检查更新`                          | 只检查 SkillHub 最新版本，不下载、不修改本地技能                                                              |
| `更新技能` / `升级技能`                 | 检查新版本，确认后下载、校验、备份并替换本地技能                                                                   |
| `自动更新技能`                        | 明确授权后自动完成检查、下载、备份、替换；失败自动回滚                                                                |
| `自检技能` / `技能找不到`                | 运行统一只读自检，定位结构、版本、语法或引用问题                                                                   |
| `审核第X章` / `诊断第X章`               | 对抗式审查+追读诊断六维                                                                               |
| `去AI味`                          | 8 Gate 清理（量化定档，防过度删改）                                                                      |
| `通读第X章` / `顺滑` / `读起来卡`         | 读感层通读修复（只治"读起来磕"：修订稿+变更清单+待确认项+读感报告，删除上限10%）                                               |
| `扩写第X章` / `润色第X章` / `衔接` / `降重` | 场景化配方库（控幅扩写/症状润色/缝合衔接）                                                                     |
| `写回顾` / `阶段回顾` / `断更复写`         | 三层回顾归档（单章微型→阶段合并→续写摘要）                                                                     |
| `回填大纲`                          | 正文事件锚点反向写回章纲                                                                               |
| `生成封面`                          | 按平台规格出封面（优先调 $story-cover/$imagegen）                                                       |
| `智能分段`                          | 发布前工具：在**已成稿**的章节里按 10%/60%/20%/10% 切出四个区间，并在区间交界处标注广告位插点（即读者读到 10%、70%、90% 处附近可插广告），只标不改文 |
| `体检` / `健康检查`                   | 档案层全书体检（扫描项+HC编号问题清单+风险分级，只告警不强锁）                                                          |
| `项目体检` / `检查目录` / `接手旧书`        | 项目骨架、章节编号、章节目录、进度行、剧本覆盖只读扫描（`tools/project_audit.py`）                                      |
| `连续性检查` / `核对时间线` / `核对伏笔`      | 角色首末出场、伏笔埋回收、时间线顺序、目录标题和回顾覆盖检查（`tools/continuity_check.py`）                                |
| `准备上下文` / `续写前打包` / `接着写第X章`    | 生成带来源哈希的 canonical 上下文包（`tools/context_pack.py`）                                           |
| `对比改稿` / `看修改差异`                | 输出字数、对话比例、删除比例和统一 diff（`tools/chapter_diff.py`）                                            |
| `快照` / `大修前备份`                  | 创建项目档案快照和 `manifest.json`（`tools/snapshot_project.py`）                                     |
| `算冲突值` / `标注章节类型`               | 给章纲/章节目录补节奏类型与冲突值（`tools/conflict_score.py`）                                               |
| `生成书名简介`                        | 书名四式10候选+简介公式3版                                                                            |
| `我卡了`                           | 5个剧情走向                                                                                     |
| `检查逻辑漏洞`                        | 连贯六类排查                                                                                     |
| `看板` / `看书` / `读正文`             | 生成可视化看板 `看板.html` 并自动打开（十分区含**正文阅读**与**写作分析**：写作热力/月度产出/质量矩阵/节奏结构/人物出场/AI味走势/伏笔健康；正文阅读支持续读记忆/←→翻章/字号/三主题/全文搜索；支持深色主题与 Ctrl+K 跳章，`tools/visualize.py`） |
| `转剧本 第X章` / `转剧本 全书`            | 章节剧本生成（写章时自动同步；老书补转逐章过检）                                                                   |
