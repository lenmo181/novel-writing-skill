# 常量表（全技能数值唯一真源）

> 本表集中存放本技能所有可调参数。SKILL.md 与各手册只做引用，不各自另立数值。
> **改数值先改这里**，再按下文「修改约定」同步脚本与手册。

## 一、篇幅与字数

| 参数 | 默认值 | 适用范围 | 备注 |
|------|--------|---------|------|
| 单章字数 | **2500-3000** | 长篇（番茄口径） | 纯正文=中文字符+中文标点；脚本 `--min/--max` 可调 |
| 起点口径 | 3000-4000 | 长篇·起点 | 起点可放宽，慢热重设定；由用户/平台指定后覆盖默认 |
| 短篇篇幅 | 8000-20000 | 短篇 | 盐选常见 5千-1.5万；黑岩 8千-4万 |
| 短剧剧本 | 按集 | 竖屏短剧/漫剧 | 不套用单章字数，按集数卡点（见短剧剧本手册） |

## 二、文本硬指标

| 参数 | 默认值 | 级别 | 执行者 |
|------|--------|------|--------|
| 对话占比 | **≥40%**（短剧剧本 ≥60%） | 硬卡 | `tools/check_chapter.py --dialog-min` |
| 单段长度 | ≤160 字 | 硬卡 | 脚本（文字墙） |
| 破折号 `——` | ≤2 次 | 硬卡 | 脚本 |
| A级禁言词 | 0 次 | 硬卡 | 脚本 |
| AI套话库单词 | ≤2 次（≥3 不通过） | 硬卡 | 脚本 |
| 「一丝」 | 全章 ≤2 | 硬卡 | 脚本 |
| 说道/问道类提示语 | 合计 ≤10 | 警告 | 脚本 |
| 比喻 | 每800字 ≤1 处（保底 2 处） | 警告 | 脚本 + Gate H |

## 三、节奏与结构

| 参数 | 默认值 | 级别 | 备注 |
|------|--------|------|------|
| 缓冲比 | **25%**（20% 可用缓冲 + 5% 校准章） | **软指标** | 仅体检提示，**不熔断**；按章数占比统计 |
| 峰值禁区半径 | **±2 章** | 硬约束（排章纲时） | 峰值章（冲突值 ≥12，★★★★☆及以上）前后各 2 章内不排「缓冲-对话」 |
| 破格配额 | **≤3 次/卷** | 硬约束（排章纲时） | 破格不得突破角色核心烙印 |
| 单章信息解密上限 | **≤30%** | 硬约束（写章纲时） | 指该线/该谜底总信息量中被本章揭示的比例 |
| 宏观节奏 | **20:30:30:20**（起:承:转:合） | 软指标 | **以卷为单位**统计，不与单章字数混淆 |
| 卷内里程碑 | 20% 中爽点 / 50% 主线反转 / 80% 最大危机 | 硬约束（排卷纲时） | 与「爽点黄金节奏」同一套里程碑 |
| 爽点间隔 | **≤3 章** | 硬下限 | 不可放宽 |
| 连续无爽点 | 任意连续 2 章须至少 1 个爽点或明显期待线推进 | 硬下限 | 缓冲章同样适用（缓冲章≠无爽点章） |

## 四、伏笔与回收

| 参数 | 默认值 | 级别 | 备注 |
|------|--------|------|------|
| Tier-3 战术伏笔沉睡阈值 | **15-20 章** | 软目标 | 超阈值未推进 → 体检告警 |
| Tier-2 战役伏笔沉睡阈值 | **30-40 章** | 软目标 | 同上 |
| Tier-1 战略伏笔沉睡阈值 | **卷末审计** | 软目标 | 每卷末必须审计一次 |
| 子链周期 | **30-40 章** | 软目标 | 一条支线期待线的最长牵引周期；**必须 ≥ 所属 Tier 的沉睡阈值**（T1 随卷长，不为 30-40 所限） |
| 核心伏笔回收率 | **≥80%** | 软目标 | 全书口径，体检跟踪 |
| 跨卷伏笔回收率 | **≥60%** | 软目标 | 跨卷埋设的伏笔中按期回收的比例 |

## 五、冲突值（见 `节奏与结构.md`，与 `tools/conflict_score.py` 1:1）

## 六、朱雀线上检测（`tools/zhuque_check.py`，EdgeOne Makers @makers/zhuque-text）

| 参数 | 默认值 | 级别 | 备注 |
|------|--------|------|------|
| AI+疑似占比硬上限 | **50%**（labels_ratio "1"+"2"） | 硬卡（有 Key 时） | ≥ 阈值退出码 1 **禁止交付**，按《去AI味手册》定向改写后重测；`--threshold` 可调 |
| AI+疑似占比警告线 | **30%** | 警告 | 过闸但须按 8 Gate 逐段过目；`--warn` 可调 |
| 送检正文下限 | 50 字 | 输入守门 | 纯正文（剥标题/格式行）不足不调用 API，退出码 2 |
| 请求超时 | 30 秒 | — | `--timeout` |
| API Key | 环境变量 `ZHUQUE_API_KEY`（或 `--key`） | — | EdgeOne 控制台 → Makers → Models → API Key 创建；每月免费 50 万 token |
| 重点分段展示 | 超标/警告时列 AI 味最重前 5 段 | — | `--segments N`（0 关闭），交 8 Gate 定向改写 |
| 全书模式重测上限 | **3 轮/章** | 软约束 | 超限或连续两轮降幅 **<5 个百分点** → 该章移交人工，跳过 |
| 全书模式章节间隔 | 1 秒 | — | `--book` 模式 `--delay`；重测只测未达标章（`--only`）省额度 |

> **可选环节**：未配置 Key 不阻塞交付（`check_chapter.py` 本地校验仍是必跑闸门）；配置 Key 后建议开篇 3 章、高潮章与平台严打期逐章跑。API/网络失败退出码 3 ≠ 超标，**不触发闸门**。阈值改动按「七、修改约定」②同步脚本默认值。

## 七、修改约定（改数值前必读）

| 档 | 参数 | 要求 |
|----|------|------|
| ① **可直接改** | 字数区间、对话占比、宏观节奏比例、缓冲比、沉睡阈值、回收率 | 改完按下方「改后必做」执行 |
| ② **改后必须同步脚本** | 单章字数（默认值）、对话占比默认值、朱雀阈值/警告线 | 必须同步 `tools/check_chapter.py`（`--min/--max`/`--dialog-min` 默认值）、`tools/conflict_score.py`（权重与峰值线）、`tools/zhuque_check.py`（`--threshold`/`--warn` 默认值），**与本表维持 1:1**，不得只改一处 |
| ③ **严禁改** | 爽点间隔硬下限（≤3 章）、平台审核红线（见 SKILL.md《平台审核红线》） | 这两项是交付底线，任何情况下不得放宽 |

**改后必做（三步，缺一不可）**：
1. 重跑一次相关校验：`python tools/check_chapter.py "<章节文件路径>"`（字数/对话改动）；`python tools/conflict_score.py --demo`（冲突值改动）；
2. 在 SKILL.md「版本历史」追加**一句**变更说明（日期 + 改了哪个数值 + 从多少到多少）；
3. 若该数值出现在各手册正文中，同步修订手册表述，避免表内表外两套数。
