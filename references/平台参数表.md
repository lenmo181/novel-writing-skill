# 平台参数表（多平台投放速查）

> **定位**：各平台写作目标参数带速查，与 `references/常量表.md` 同构（番茄=常量表默认值的展开；其他平台=在默认值上的偏移）。
> **证据等级**：A=热榜实证（R1-R7 官方口径）｜B=多源一致｜C=经验带（待扫榜验证）。
> **铁律**：本表是**写作目标带，不是平台官方规范**——投稿前以平台当日后台、合同与编辑口径为准，**不编造数据**（全局配置「默认平台」条款）。
> 程序侧：`tools/config.py` 的 `PLATFORM_PRESETS` 只收字数带与对话区间（脚本默认值真源）；校验传 `check_chapter.py --platform <名>`，显式 `--min/--max/--dialog-min/--dialog-max` 优先于平台预设。

## 二、跨平台不变量（任何平台不得豁免）

- A级禁言词 0 次、格式纯净、无元信息残留——30项校验第3/6/7项，平台无关。
- 前3章生死线（黄金开篇铁律）——免费流（番茄/七猫）更严：开篇即争夺推荐位。
- 平台审核红线（涉政/真实人物/未成年/暴力过程细节/性描写）全平台从严，宁淡不写（细则见《写作铁律.md·平台审核红线》）。
- 对话三症状、光杆「他说：」分级——全平台 AI 指纹，不分平台。

## 三、用法

1. **写作**：初始化/写章指令里声明平台（不声明=番茄默认）；书格 `mind/书格.md` 记录 `平台=起点` 后全链路按本表偏移。
2. **校验**：`python tools/check_chapter.py "书稿/第001章_X.md" --platform qidian`（自动切字数带/对话区间；`--chapter-index` 前3章闸门不受平台影响）。
3. **扫榜补充**：本表 C 级条目经 `扫榜.md` 流程取证后升级，并按《规则台账》登记证据；禁止凭印象改 A/B 级行。
4. **封面**：比例与调性详见 `references/封面.md`（封面出图与质检真源），本表只做速查列。
