# 扫榜手册（长篇+短篇市场调研）

> 触发：`扫榜/市场调研/什么题材能写/最近什么火`。

## 五阶段流程

1. **确认方向**：有明确方向→深扫该题材；无方向→全榜概览；用户要对比→跨平台对比
2. **确定数据来源**（优先级）：**平台榜单人工采集** > 用户提供（截图/链接/文字）> 内置知识（**必须标注"候选假设未校验"**）
3. **数据分析**（维度见下）
4. **扫榜报告**（模板见下）
5. **选题决策**（四步法）

## 数据质量硬检查（采集后必跑4项）

1. 条目 ≥15（小平台 ≥10，不足标 `[数据稀疏]`）
2. 必填字段齐全：排名/书名/作者缺一即无效
3. 清洗：删模板文本、解析错串行删除重采、空字段标 `[待补]`
4. 简介超100字在句末截断；文件头必须写「数据质量/有效条目/问题摘要」

## 分析维度

**长篇7项**：题材分布 / 新题材信号 / 经典题材变化 / 字数与更新 / 书名模式 / 开头卖点 / 新元素对比（新人物设定/新开篇切入/新桥段）
**短篇7项**：情绪类型分布（虐恋/反转/悬疑/治愈/打脸）/ 题材热点 / 篇幅分布 / 开头模式（第一段第一句）/ 结尾类型（HE/BE/开放比例）/ 标题模式 / 人设模型

## 风口预警三态（短篇必做）

- 🔥 正在爆发 / ⚡ 即将起风 / ⚠️ 即将饱和，各附依据
- **短篇风口数周内失效**：报告必须标注样本日期、趋势可信度、建议复扫时间；未复扫不得当长期趋势

## 报告模板

题材（或情绪）热度排行表 → 新题材信号/新元素提取 → 关键数据洞察（字数区间/日均更新/书名特征/标签热词）→ 风口预警 → 值得写的方向（含可行性评估）→ 一句话犀利总结

## 选题决策四步法

1. 能爆的原因（情绪/题材/钩子拆解）
2. 市场验证（榜单数据支撑点）
3. 差异化定位（和榜上已有书怎么错开）
4. 可行性+失败风险+验证动作

**硬规则**：样本 `[数据稀疏]` 或 <15条 → 可行性强制降"中"；内置知识模式一律"中"；不输出项目素材撑不起的题材。产出落盘 `选题决策.md`，写书时回填验证。
