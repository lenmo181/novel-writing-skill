# 运行时兼容与安装（v7.27）

本手册解决技能包在 Codex、ZCode、Windows PowerShell、CMD 与 Bash 之间的路径和环境差异。

## 路径约定

- `<SKILL_ROOT>`：当前 `SKILL.md` 所在技能目录；禁止写死用户名、`.zcode` 或具体磁盘路径。
- `<PROJECT_ROOT>`：当前小说项目根目录；用户显式指定路径优先，其次读取环境变量 `NOVEL_PROJECT_ROOT`，最后使用当前 Codex 用户的 `~/.codex/workspace/novels/`。
- 外部调用只接受显式的 `<PROJECT_ROOT>`，不根据当前工作目录猜测小说项目。

## 环境变量写法

PowerShell：

```powershell
$env:ZHUQUE_API_KEY = "你的Key"
$env:MOCHI_RULER_DIR = "墨尺仓库路径"
$env:NOVEL_PROJECT_ROOT = "小说项目根路径"
```

CMD：

```bat
set ZHUQUE_API_KEY=你的Key
set MOCHI_RULER_DIR=墨尺仓库路径
set NOVEL_PROJECT_ROOT=小说项目根路径
```

Bash：

```bash
export ZHUQUE_API_KEY="你的Key"
export MOCHI_RULER_DIR="墨尺仓库路径"
export NOVEL_PROJECT_ROOT="小说项目根路径"
```

## 外部服务与隐私

- 朱雀会把纯正文发送到外部检测服务；未得到用户明确同意时跳过，不以“可选”代替告知。
- 封面生成只使用用户指定的服务、已明确授权的内置能力或本地工具；不默认写入第三方中转站地址。
- API Key 只从当前进程环境或显式参数读取，不把 Key 写入技能文件、项目档案、报告或版本库。
- 外部服务失败、超时、额度不足均只产生可见的“未检测”状态，不得伪装成通过。

## 安装与升级

从源目录执行：

```powershell
python tools/lint_skill.py
python -m unittest discover -s tests -p "test_*.py"
powershell -ExecutionPolicy Bypass -File tools/sync_skill.ps1
```

`sync_skill.ps1` 默认同步到当前用户的 `.codex\skills\网络小说创作技能`；如需其他宿主，使用 `-Destination` 显式指定。
