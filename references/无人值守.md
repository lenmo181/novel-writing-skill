# 无人值守写作手册（定时任务/自动续写）

> 触发：`无人值守写作/定时任务/自动续写/挂机写书/批量写作`。适用所有"每轮N章循环写"的部署形态。

## 防腐烂铁律（第一原则）

- **任务提示词禁止硬编码技能数值**（字数区间/对话占比/单段上限/禁词限额等）——数值只写在本书 `mind/书格.md`，提示词规范行统一写：**「以 `SKILL.md` 当前版本铁律为准（对话归位六式、无引号内心戏≥5、开篇三句入戏、字数区间按书格）」**
- 历史教训（v7.15/v7.16 复盘）：定时任务把旧版数值快照进提示词，技能升级后照旧按旧规写作——实测某书近章「他说」类光杆引导 11-18 次/章（热榜≈0），1000+ 章带病产出
- **技能每次升级后**：对每本在写书抽最新 3 章跑 `tools/check_chapter.py`，确认任务输出跟上新规；没跟上说明提示词里还藏着硬编码数值

## 标准任务提示词模板

```
无人值守写作：续写《书名》（<项目根绝对路径>），每轮N章，从 mind/章节目录.md 进度行的下一章起按既有大纲推进。
【规范】先读 C:\Users\lenmo\.zcode\skills\网络小说创作技能\SKILL.md「模式路由表」→ 长篇模式；铁律以 SKILL.md 当前版本为准（对话归位六式、无引号内心戏≥5、开篇三句入戏、A级禁言词、格式与元信息残留零容忍）；本书数值与专属风格以 mind/书格.md 为准，校验旗标照书格映射表传参。
【档案权威】mind/ 七档案（章节目录兼进度表；伏笔/正史/路线权威按本书指定）。
【流程】1) 读进度行定起始章；2) 先跑 check_chapter.py 于上一章，烂尾（字数<下限）先补完再开新章；3) 逐章写正文→落盘→跑校验（非0先修，历史风格差异记 mind/剧情走向锁定.md 后放行）；4) 更新 mind/ 档案；5) 输出【断点】已完成至第X章 | 下一章：X+1 | 待办：XXX。
【硬规则】严禁压缩结局/提前收尾；锁定章号不重写；只有路线权威文件终章条件达成才许标（全书完），已完本只报状态；元信息行（更新时间/字数统计）禁止写入正文。
【调度】每45分钟一轮（或用户指定）。
```

## 书格覆盖机制（mind/书格.md）

每本书可建 `mind/书格.md` 声明本书专属风格；**节奏类可覆盖，交付底线不可豁免**：

| 字段 | 默认（=技能值） | 可否覆盖 | 示例 |
|------|----------------|---------|------|
| 字数区间 | 2000-2500 | ✅ | 千门系 2400-2800 |
| 引号口径 | chal（中文弯引号） | ✅ | 千门系：对白不加引号 → `--quote any` |
| 对话占比 | 15-50（健康指导 25-50） | ✅ | 无引号流填「不适用」→ `--dialog-min 0 --dialog-max 0` |
| 风格法 | 无 | ✅ 新增 | 短段白描/灯语拆位制/禁省略号破折号/禁英文词泄漏 |
| A级禁言词/AI套话/他说硬卡/元信息残留/格式 | 0/0/>5硬卡/0/0 | ❌ 永不 | —— |

**校验旗标映射**（提示词里写明，脚本无需改）：
- 无引号对白流：`--quote any --dialog-min 0 --dialog-max 0`
- 自定字数：`--min X --max Y`
- 其余项一律用默认值，随技能版本自动升级

## 目录兼容

- **标准目录**：`书稿/第NNN章_章名.md`（新书一律用这个）
- **遗留兼容**：`正文/`、`小说分章/*.txt+根目录主txt`——老书按本书既有目录续写，**禁止同一本书出现第二种正文目录**；能迁移时整卷迁移并更新断点记录

## 烂尾章检测

每轮开工第一件事：对上一章跑 `check_chapter.py`。字数低于书格下限=上轮中断（实例：某书末章 1444 字断在对白中间），**先补完上章再写新章**，禁止跳章。

## 断点与备份

- 断点行格式不变；每轮收尾跑 `tools/cloud_sync.py` 镜像同步（软门禁，失败留痕不阻塞）
- 移交人工的条件照旧：3轮不达标/连续两轮无涨幅 → 断点明标，禁止静默当完成
