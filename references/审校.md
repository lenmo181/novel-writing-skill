# 审校手册（对抗式审查+追读诊断+校对过审）

> 触发：`审核第X章/审这一卷/诊断第X章/校对`。与"审稿卡"的关系：审稿卡是单章快评（主文件），本手册是深度审查。
> **分工**：本手册管**单章**；`体检/健康检查/设定库诊断/连续性体检` 走 `references/体检.md`（档案层全书体检）。

## 对抗式审查（找问题，不是验证正确）

单章用 solo 深审；整卷/多章分四视角过一遍（有子代理能力就并行，没有就顺序自查）：

1. **结构视角**：章尾是否落在动作/画面/悬念（章尾总结腔=水文信号）；场景目标→阻碍→转折是否完整；节奏是否均匀化（均匀=AI味）
2. **角色视角**：**对话三症状**——机械问答式（你一句我一句 symmetry）/ 科普嘴（借角色嘴讲设定）/ 不分场合插科打诨；人设决策一致性
3. **文笔视角**：8种AI模式+解释腔；删掉无损的任务卡点句（"为了确认这一点，他…"）；碎句/电报体与AI腔**同级处理**，不因"短=网文节奏"放行
4. **一致性视角**：字面冲突（grep-first）+ **推理型一致性**——规则边界（能力能不能这么用）/ 设定层级 / 跨章因果链 / 可滥用漏洞（读者会不会问"为什么不直接XX"）/ 代价一致性（能力用的代价前后一致）

## Findings 分级（S1-S4）

- **S1** 破坏主线动机/规则信任 → 立即修
- **S2** 明显影响留存/节奏 → 本轮修
- **S3** 局部瑕疵 → 排期修
- **S4** 建议 → 酌情
每条 finding：级别 + 类别（structure/character/prose/consistency/platform/factual/format/causal/rule_boundary）+ 位置（章节+原句）+ 问题 + 修法。consistency 类只写事实统一方向，不写文学建议。

## 追读诊断六维（读者留存视角，逐章打分1-5）

钩子（开头3句+章尾）/ 爽点（兑现或期待线推进）/ 伏笔（埋收有序）/ 人设（言行一致有记忆点）/ 节奏（快慢交替无水文）/ 人味（活人感五件套）。
总分≤18/30：该章建议返修。输出含"最危险的三分钟"——读者最可能在哪一段划走。

## 连贯检查六类（防百万字失忆，整卷/整书时跑）

**行为 / 因果 / 资源 / 身份 / 伤势 / 战力** 六类前后矛盾逐一排查，对照 mind/ 快照+时间线+锚点日志；产出矛盾清单（章A说X，章B说Y，应以何为准，怎么改）。

## 专项检查

- **开头新鲜度**（仅前3章）：这段开头能整体换到任意同类书里吗？能=同质化，即使有钩子也至少算问题
- **具体字数表达校验**：正文写"这五个字/短短四字/八个字砸下去"，必须机器核对确实五个字，否则改成"这句话一落"等非具体数字表达
- **模型退化检测**（AI生成正文时）：逐字复读/打转、末尾截断、占位符残留、工程词泄漏（"细纲""情节点"等写作术语进正文）→ **重新生成，不是改写**

## 校对过审（发布前最后一道）

- 错别字：的地得/在再/作做/账帐 等高频混淆
- 敏感违禁词：对照主文件"平台审核红线"逐条扫，输出"原词→建议词"替换表
- 引号/标点统一性复核（对照引号配置）

## 收尾

- findings 全部处置后重跑校验脚本，摘要行更新进 `mind/章节目录.md`
- 整卷审查分批时：维护 `.story-review/state.md` 继承开放项（已埋未收的伏笔+上批未解决findings），默认记待办，不盲目全量重跑
