# 小说转剧本手册（章节剧本，随章同步）

> 触发：`转剧本 / 本章剧本 / 章节剧本 / 小说转剧本`；**写章流程第五步自动执行**（正文落盘后同步生成本章剧本，v7.21）。
> 格式与卡点铁律**完全复用《短剧剧本》手册**（场景头/△动作行/角色名：台词/【字幕】），本手册只定义"逐章转换协议"，不另立格式。

## 一、落盘与命名

- 目录：`<项目根>\剧本\`（项目模板 v7.21 起预建；老项目首次转剧本时创建）
- 文件：`第XXX章_章节名.md`（与书稿同名对应，一章一文件）
- 首行标记：`第N章 章节名（改编剧本）`
- 剧本/ 目录自身就是台账：文件在=已同步，无需另记表；断点记录追加「剧本✓@第X章」

## 二、转换协议（六章→一集，逐场手术）

一章 2000-2500 字 ≈ 一集（1500-2500 字剧情量），场景 2-4 个。转换是**场景化重写，不是逐句翻译**：

| 正文元素 | 剧本处理 |
|---------|---------|
| 对白 | 保留骨干，口语化提纯；单句 ≤15 字优先；光杆引导语删除（剧本天然不需要） |
| 动作描写 | 收进 △ 行，只写镜头能拍到的 |
| 心理描写/无引号内心戏 | **全部外化**：动作+台词，必要时「闪回」画面标注 |
| 环境描写 | 压进场景头（内/外-地点-时间）+ △ 关键可见物，不超过 1 行 |
| 面板/系统文本 | 【字幕】字卡，每章 ≤2 处 |
| 时间跳转 | 旁白仅限衔接跳转，每章 ≤2 处 |
| 章末钩子 | 转为尾场景**强卡点**（画面+台词双钩），与正文章末钩子同源——剧本卡点=钩子DNA的剧本形态，章名三对齐扩为"章名-正文钩-剧本卡点"三对齐 |

**红线**：不改剧情事件与因果；不改人物关系与信息差；爽点落点必须保留在台词或动作上；正文过审红线的处理（留白/切镜头）在剧本里同样执行。

## 三、质检（双层）

1. **机械**：`python tools/script_check.py "<剧本文件>"`（退出码 0/1/2）——场景块 2-4、对白占比 ≥60%（45-60 警告，<45 硬卡）、心理词残留（心想/暗道/心中）=0、【字幕】≤2、△单行 ≤60 字、无对白连续区 ≤15 行、末场景须有台词卡点。
2. **人工/AI**：卡点强度、转场可拍性、人物语言指纹（对照 mind/角色状态快照 的说话方式）。

不达标当场修剧本（只动病灶场景），复测过检才算同步完成。

## 四、同步时机（铁律）

- **写章流程第五步**：正文落盘+档案更新后，**立即生成本章剧本并过检**，才算本章完成——禁止攒批补转。
- `续写`/`一键生成`/无人值守模板同一流程，断点记录带「剧本✓@第X章」。
- 老书补转：`转剧本 第X章` 单章触发，或「转剧本 全书」批量（每章独立过检，进度写 mind/剧情走向锁定.md）。
- 改剧本不改正文：若转剧本时发现正文硬伤（信息差错/钩子丢失），**先修正文再转**，不得在剧本里悄悄改剧情。
