# 模式操作卡（v7.39，10 卡）

这份卡片是路由速查，不替代各模式手册。第一次使用先读[快速开始](快速开始.md)，工具职责看[工具选择](工具选择.md)；需要选择主流程时再回到本页。同一请求包含多个动作时，只有不改变权限和产出边界的后续动作才能自动串联。

## 统一字段

每张卡都回答六件事：

1. **触发**：用户怎么说才进入本卡。
2. **最小输入**：缺什么时可以默认，缺什么必须停下确认。
3. **默认级别**：快速级、标准级或深度级。
4. **允许修改**：本流程可以写哪些项目文件。
5. **停靠条件**：什么时候必须等待用户裁定。
6. **交付回执**：状态、变更、证据、下一步。

## 卡 1：长篇写作 / 续写

- **触发**：`初始化项目`、`写第X章`、`续写`、`日更`、`一键生成`。
- **最小输入**：新书需书名、题材、规模；存量书需项目根或当前工作目录；章节号缺失时可读取断点。
- **默认级别**：完整章节走标准级；片段或草稿走快速级；“全书/深度”才走深度级。
- **允许修改**：`书稿/`、直接依赖的 `mind/`、单章回顾和按项目需要的 `剧本/`。
- **停靠条件**：章纲缺失、已锁定设定冲突、重大结局变化或连续三轮钩子越界。
- **交付**：正文落盘、校验退出码、档案更新、下一章断点。

## 卡 2：短篇写作

- **触发**：`写短篇`、`知乎盐选`、`番茄短篇`、`短故事`。
- **最小输入**：题材、核心冲突、目标字数；缺项先给 2-3 个可选方向，不凭空锁定结局。
- **默认级别**：标准级；只要片段时快速级。
- **允许修改**：短篇正文、必要的结构记录和校验报告；不自动创建长篇七档案。
- **停靠条件**：平台口径、第一/第三人称或结局方向会改变成稿时先确认。
- **交付**：短篇正文、平台格式检查、结构问题和可选修订项。

## 卡 3：短剧 / 漫剧 / 小说转剧本

- **触发**：`写短剧剧本`、`漫剧分集`、`小说改剧本`、`转剧本`。
- **最小输入**：原文或故事设定、集数/单集时长、平台格式；缺集数时先按一集样稿处理。
- **默认级别**：标准级；全书补转或批量质检走深度级。
- **允许修改**：`剧本/` 或用户指定的脚本文件；原正文默认只读。
- **停靠条件**：原文事件缺口、人物关系不明、单集结尾无法形成卡点。
- **交付**：分集剧本、场景/对白/心理残留质检、下一集卡点说明。

## 卡 4：扫榜 / 选题 / 热榜研究

- **触发**：`扫榜`、`最近什么火`、`选题`、`热榜研究`。
- **最小输入**：平台、题材、时间范围或样本范围；未指定时只做方法说明，不虚构最新榜单事实。
- **默认级别**：深度级；只要选题方向时快速级。
- **允许修改**：研究报告、题材卡、知识库轮次记录；不改正文。
- **停靠条件**：需要联网取证但用户未授权，或样本范围会明显改变结论。
- **交付**：事实来源、可迁移规律、选题决策、不可直接照搬的元素清单。

## 卡 5：拆书 / 拆文

- **触发**：`拆书`、`拆文`、`学习某作品写法`。
- **最小输入**：作品文本或合法可读样本、拆解维度；缺样本时只输出拆解模板。
- **默认级别**：标准级；全书结构和多样本对照走深度级。
- **允许修改**：拆解报告、文风样本、知识库；不复制大段原文，不覆盖正文。
- **停靠条件**：素材不可读、来源不明或用户要求复刻原文风格到近似替写。
- **交付**：结构规律、节奏/人物/钩子拆解、可迁移原则和禁复制边界。

## 卡 6：导入旧书 / 初始化续写

- **触发**：`导入旧稿`、`继续写旧书`、`初始化续写`、`接入旧项目`。
- **最小输入**：项目根目录或旧稿目录；缺路径时不能猜另一本书。
- **默认级别**：标准级的只读盘点阶段；用户确认后才进入写章。
- **允许修改**：新增或映射 `mind/` 档案、报告和目录；已有正文只读。
- **停靠条件**：双源冲突、章纲断档、人物状态无法判定、缺少关键设定。
- **交付**：映射表、缺口清单、待补充项、可续写断点。

## 卡 7：审校 / 通读 / 去 AI 味

**v7.39 交付证据**：正式章节验收使用 `chapter_readiness.py --with-semantic`；第14-30项必须逐项记录 `status + evidence`，这样语义审校结果才能被后续复测和发布门机器消费。

- **触发**：`审校`、`诊断`、`通读`、`顺滑`、`去AI味`、`润色`。
- **最小输入**：文件或章节范围、重点问题、是否授权直接修改。
- **默认级别**：只审不改为快速/标准只读；明确授权修订或全书检测才进入深度级。
- **允许修改**：只有用户授权后才修改正文；报告、差异和快照可先生成。
- **停靠条件**：删除超过 10%、触碰伏笔/钩子/因果/人物状态，或检测需要外发正文。
- **交付**：问题证据、修订稿、差异报告、待确认项、复测结果。

## 卡 8：封面

- **触发**：`生成封面`、`封面提示词`、`封面质检`。
- **最小输入**：书名、笔名、平台、题材和构图方向；缺书名/笔名必须补问。
- **默认级别**：标准级；多轮重出或平台批量适配走深度级。
- **允许修改**：`封面/` 下的提示词、图片版本和质检报告；不改正文档案。
- **停靠条件**：没有出图能力、文字渲染不清、安全区不合格或超过三轮重出。
- **交付**：图片或可执行提示词、比例/尺寸检查、版本和不合格点。

## 卡 9：技能自检 / 更新

- **触发**：`自检技能`、`技能找不到`、`检查更新`、`更新技能`、`自动更新`。
- **最小输入**：通常无需额外输入；自定义安装目录才需要路径。
- **默认级别**：只读检查；更新必须由用户明确授权。
- **允许修改**：自检不修改；更新只修改技能安装目录，先备份，失败回滚。
- **停靠条件**：版本回退、包校验失败、路径不安全、替换失败或用户只要求检查。
- **交付**：本地/远端版本、检查证据、备份位置、更新结果或恢复命令。

## 卡 10：全文审稿 / 全书诊断（v7.33）

- **触发**：`全文审稿`、`全书诊断`、`修稿队列`、`这本书问题多不多`、`P0问题`。
- **最小输入**：项目根目录（含 书稿/第XXX章_*.md）。
- **默认级别**：只读诊断（full_review.py + 体检口径 P0-P3），`--strict` 仅用于发布门改退出码。
- **允许修改**：**不修改任何文件**；报告落盘 mind/全文审稿报告.md 是唯一写动作。
- **禁止修改**：正文、档案、大纲——修复动作一律逐项人工确认后由对应流程执行（单章→审校/去AI味；跨章→补纲+变量注入；设定→档案修正）。
- **停靠条件**：扫描为空（无章节文件）退出码 2；发现 P0 时**停下报告**，不自动修复；全书问题（如主线疲软）移交用户决策，不当单章问题修。
- **交付**：P0-P3 计数 + 按级别/类别排序的修复队列（位置/问题/建议动作）+ 报告路径 + 与单章审校的分工说明。

## 复合请求判定（v7.39）

先锁定权限与外部数据边界，再确定主创作动作，再挂附加诊断。只要两个动作会产生不同写入范围、外部传输或剧情变化，就拆成两个阶段并停在确认点；只有“写完后本地检查”这类不改变权限边界的动作允许自动串联。



按以下优先级选主流程：

1. 用户明确的只读限制、隐私限制和“不许修改”；
2. 技能更新、安全检查和其他高风险维护动作；
3. 明确的主要创作动作；
4. 诊断、报告和可选产物；
5. “继续”“帮我看看”等泛化请求。

如果两个动作会产生不同文件修改、外部联网或改变剧情，必须拆成两个阶段并停在确认点；如果只是“写完后做本地校验”，可以作为主流程的内置步骤自动执行。
