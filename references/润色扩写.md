# 润色扩写手册（场景化配方库 + 两段衔接 + 回填大纲）

> 触发：`扩写第X章` / `润色` / `这章太短` / `太干了` / `衔接这两段` / `水了一段` / `回填大纲`。来源：PromptLibrary 扩写润色配方族整合。
> 总铁律（所有配方共用）：**剧情锁死**——核心事件、人物对话要点、关键转折、结局全部不变；只动"怎么讲"，不动"讲了什么"；只输出成品正文，不附解说、对比、批注。

## 通用铁律（每次必执行）

1. **改前建约束锁**：目标篇幅（原文字数×目标幅度）、必保留情节清单（从单章回顾抄）、禁止新增内容
2. 扩/润后**必须重跑 check_chapter.py**——字数、对话占比、AI味指数都会漂，掉出区间回补对话
3. 设定为唯一标准：全程贴合世界观/角色卡，发现原文与设定冲突→按设定修正并在交付说明里列出（不静默改）
4. 交付报告三行：原文字数 / 成品字数 / 净变化幅度（对准目标幅度，偏差>10% 说明原因）

## 扩写配方（按目标幅度选）

| 配方 | 幅度 | 适用 | 加什么 |
|------|------|------|--------|
| A 轻度扩写 | +20% | 章节略薄、细节不足 | 环境铺垫、肢体微动作、感官细节（触/嗅/声/视线）、简短内心碎碎念（贴人设）；不加新事件 |
| B 深度扩写 | +50%-80% | 大纲赶出来的骨架章 | 分层填充：环境→身体感官→多层心理→微动作停顿；强化情绪反差；把直白叙述改写成主角实时感受 |
| C 精准控幅 | +30%左右 | 微调篇幅 | 只补四类：环境/微动作/瞬时心理/感官；同时剔除重复冗余，"扩中带减" |
| D 水段救场 | 翻倍以内 | 剧情单薄、过渡空白 | 环境描写+人物心理复盘+处境碎片思考+少量往事对照；**不新增支线不偏主线**，全部服务当下情绪与后续铺垫 |
| E 开篇强化 | +50%-70% | 前三章 | 濒死/危机/穿越体感具象化（痛感、耳鸣、视线扭曲、窒息感）、情绪反差对比、新旧身份落差；仍守黄金开篇禁开头8条 |
| F 冲突高潮强化 | +50%-60% | 打脸/觉醒/决战章 | 前置铺垫压迫感层层加码→爆发瞬间感官剧变→反击动作逐拍细化→穿插过去无力 vs 现在翻身的对比；节奏先慢后快 |

扩写共同禁区：不新增独立剧情支线、不改任何对话的信息量、不提前揭露伏笔、凑字数的重复场景描写。

## 润色配方（按症状选）

| 配方 | 适用 | 动作 |
|------|------|------|
| G 基础语病流 | 生硬、书面腔 | 修病句/逻辑断层/重复用词；平淡段加细微心理；书面语换口语；保留全部剧情对话 |
| H 氛围强化 | 开篇/转折/重场 | 补环境细节与身体感官烘托当下情绪；直白陈述改侧面感受；禁文艺腔堆砌 |
| I 爽文节奏 | 打脸/逆袭/权谋段 | 压缩拖沓描写、前置冲突铺垫、放大心理反差、冲突段短句化；只调节奏不动剧情 |
| J 心理深度 | 内心戏单薄 | 补贴人设的内心活动：口语化、不矫情、不打断主线；触发情绪的事件要能在前文找到 |
| K 精简微调 | 小修 | 只改错别字/重复词/生硬句，篇幅基本不变 |

## 两段衔接（缝合 AI 分段生成的割裂感）

长章分段生成、或拼接两次会话的产出时用：

1. **不变更两段全部事件与互动细节**，依靠光影变化、身形小动作、体感变化、时间流逝搭建自然过渡，消除段落割裂
2. 统一镜头叙事逻辑：环境全景→人物身形→互动→局部特写，画面流转连贯
3. 统一措辞与句式节奏，消解分段生成的文笔割裂
4. 衔接缝前后各300字重点复查：人称、时态、称谓、情绪连续性
5. 只输出衔接润色后的完整正文

## 降重改写（重复剧情/水段翻新）

- 核心：核心剧情、人物、事件顺序不变；**句式、词汇、叙事角度全部重写**
- 新增少量细碎心理吐槽换质感；文风保持原书基调；篇幅上下浮动≤10%
- 适合：同类场景写多了自我重复、平台查重、旧稿复用

## 回填大纲（正文领先于纲时，写完反向补锚点）

用于"先写后纲"或偏离章纲写完后同步档案：

把写完的章节精炼成事件锚点，插到 章纲.md 对应章号下：

```
第X章：章名
- 章节概要：（一句话）
- 主要事件结点：事件1…事件2…（1-2句/条，含冲突+结果）
- 关键锚点：心理/冲突…；伏笔（编号）…；关系变化…
- 写作提示：（节奏/重点/情感，给下次重读用）
```

要求：结点是"AI一看就能展开成完整章节"的锚，不是散文；同步更新 mind/伏笔追踪表与单章回顾。

## 场景细化参照（扩写时给感官找抓手）

写哪类场景就调动哪套细节，**细节必须服务剧情或情绪，不为文艺而文艺**：

- 危机/战斗：痛感、耳鸣、呼吸、视线、地形容势、装备状态
- 权谋/对峙：微表情、座次、谁先开口、茶杯与文件的小动作、门外的动静
- 日常/温情：食物、天气、物件旧痕、口头禅、生活废话说半截
- 情感转折：沉默长度、错开的视线、重复的小动作、话说一半收住
