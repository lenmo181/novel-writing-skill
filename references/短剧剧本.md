# 短剧剧本手册（竖屏短剧/漫剧）

> 触发：`写短剧剧本/把小说改成剧本/漫剧分集`。

## 格式规范（正规格式，只写能拍的）

```
第X集

场景1 内景/外景-地点-时间
△ 动作描述（只写镜头能拍到的，不写心理活动）
角色名：台词
（角色名）：低声/冷笑等语气标注
【字幕】关键信息字卡（慎用，每集≤2处）
```

- **△开头的行为行**只写可见动作和表情；心理描写转为：动作外化+台词+闪回画面
- 每集=一个完整情绪单元，时长对应竖屏短剧1-3分钟/集（漫剧可到5分钟）
- 小说改剧本：一集约对应小说1500-2500字剧情量

## 卡点铁律

- **每集结尾必须强卡点**：反转/危机/身份揭露/打脸前一秒，用画面+台词双钩
- 前3集定生死：第1集前10秒必须出冲突或奇观；黄金3集内金手指/核心设定亮完
- 付费卡点（如平台有）：优先卡在大反转前一集结尾
- 对白占比 ≥60%（剧本比小说更依赖台词）；单句台词≤15字优先

## 与小说模式的差异速查

| 维度 | 小说 | 短剧剧本 |
|------|------|---------|
| 心理描写 | 可用（Show don't tell） | 禁止，全部外化 |
| 场景数/集 | 自由 | 2-4个，转场要省钱省事 |
| 台词 | ≥40% | ≥60%，口语化 |
| 旁白 | 少用 | 仅不得已时衔接时间跳转 |
| 校验 | check_chapter.py | 人工核对卡点+格式，脚本不适用 |

## 漫剧补充（AI漫剧分镜向）

- 每场给出：画面主体/景别（远全中近特）/时长秒数，方便直接喂分镜
- 角色形象一致性提示词记入 `设定/角色.md`（服装/发色/标志物固定描述）
