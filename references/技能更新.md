# 技能更新手册

## 目的

本技能的更新器只处理 **Codex 技能安装目录**，不读取、不覆盖小说项目目录。更新源是 SkillHub 的公开下载接口：

```text
https://api.skillhub.cn/api/v1/download?slug=@user_cd8383ec/web-novel-writing
```

## 三种模式

### 1. 检查更新（默认安全）

只读取远程版本，不下载、不改文件：

```powershell
python tools/update_skill.py --check
```

退出码：`0`=已是最新或无变更，`2`=检测到新版本，`1`=检查失败。

### 2. 确认后更新

检测到新版本后提示确认；确认后才下载、校验和替换：

```powershell
python tools/update_skill.py --update
```

### 3. 自动更新

只在用户明确要求“自动更新技能”时使用：

```powershell
python tools/update_skill.py --auto
```

自动更新包含以下安全门：

1. 先对比本地 `SKILL.md` / `tools/config.py` 版本与 SkillHub 最新版本。
2. 下载 ZIP 到临时目录，不直接覆盖现有技能。
3. 校验 ZIP 路径，拒绝 `..` 穿越路径和符号链接。
4. 校验包内必须存在 `SKILL.md` 与 `tools/config.py`，并核对包内版本。
5. 更新前复制当前技能到 `~/.codex/skill-update-backups/`。
6. 替换失败时自动恢复备份。

## 约束

- 普通写作任务不隐式联网，也不自动替换技能。
- `--auto` 只更新 Codex 技能目录，默认是 `~/.codex/skills/网络小说创作技能/`。
- 用户小说项目、`NOVEL_PROJECT_ROOT` 指向的目录和 `mind/` 档案不会被更新器触碰。
- 若更新后 Codex 仍显示旧内容，重启 Codex 或重新加载技能列表。

## 备用参数

```powershell
python tools/update_skill.py --check --json
python tools/update_skill.py --update --yes
python tools/update_skill.py --auto --destination "D:\\custom\\skills\\网络小说创作技能"
python tools/update_skill.py --update --force
```
