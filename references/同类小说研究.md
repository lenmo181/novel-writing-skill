# 同类小说研究与剧情仿写边界

> 触发：`同类小说`、`剧情仿写`、`找三本参考`，或写章前项目配置已开启研究。工具：`tools/similar_novels.py`。

## 能力范围

工具默认从 TTNovels（`https://ttnovels.com/`）按项目题材挑选最多 3 本不同作者的作品，读取公开分类页、详情页的书名/作者/分类/状态/字数/更新时间、简介短摘和章节标题，生成：

- 每本作品一张“前提—引爆点—主线驱动—压力与代价—目录节奏信号”结构卡；
- 把视角只当作可迁移的结构变量：本项目默认第三人称单主角限知，必要时才少量切换角色视角；不因参考作品的多视角写法自动改成群像；
- 只可迁移的冲突链、节奏功能和钩子位置；
- 草稿与研究材料的连续片段重合提示。

工具不下载、保存或输出章节正文，不把原作情节按章节顺序改写成新稿。简介短摘只作项目内私有研究记录，报告保留来源链接和抓取时间，便于复核或删除。

## 开启与写章接入

初始化项目会创建 `研究/同类小说配置.json`，默认关闭联网：

```json
{
  "enabled": true,
  "allow_network": true,
  "source": "https://ttnovels.com/",
  "count": 3,
  "refresh_hours": 24,
  "request_interval": 0.75
}
```

用户明确允许联网后，执行：

```bash
python tools/similar_novels.py "<项目根>" --allow-network
```

也可临时指定题材并强制刷新：

```bash
python tools/similar_novels.py "<项目根>" --genre "惊悚悬疑" --count 3 --allow-network --refresh
```

报告写入 `<项目根>/研究/同类小说研究.json` 和 `.md`。24 小时内同题材结果自动复用缓存；网络不可用时保留旧报告，不阻塞写作。`robots.txt` 明确禁止的路径不会读取；当站点暂时无法提供 robots 文件时，工具仍限制为公开页面、最多 3 本和低速访问，并在报告中留痕。

## 原创性护栏

写章时只吸收结构功能，必须重新设计：

1. 人物目标与关系；
2. 场景、道具和世界规则；
3. 冲突的因果链、代价和转折顺序。

视角也必须重新设计：默认让主角承担读者信息入口；确需切换时只在场景边界短暂落到一个角色，写清切换服务的信息差或危机，不在同一段跳入多个人物内心。

禁止复用书名、角色名、专有名词，禁止出现连续 12 字以上的来源原句，禁止沿用单本作品的章节顺序。草稿完成后可运行：

```bash
python tools/similar_novels.py "<项目根>" --check-draft "<章节文件>"
```

高风险结果只表示需要重写和人工复核，不是法律意义上的抄袭结论；应优先替换人物动机、场景机制和代价，再复测。

## 写作流程挂接

在《长篇模式》第一步读取项目配置。`enabled=true` 且已授权时，写本章前先运行研究工具，将结构卡加入约束锁；未开启、未授权、超时或无结果时，回执写明“同类小说研究未完成”，继续使用本地大纲和项目档案，不把网络失败伪装成已参考。
