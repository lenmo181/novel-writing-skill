# 拆文手册（爆款拆解）

> 触发：`拆书/拆文/学习《XXX》/分析这本书`。拆解产出的写法档案写作时可调用（对应主文件"百万小说库"能力：配置库路径后自动应用）。

## 长篇拆解管道（Stage 0-6）

- **Stage 0 概要+章节边界**：先出200字概要；建立**章节边界表**（唯一切片真值，后续全部共用）；多卷书章号全书连续重编；落表前校验章号连续/无重复/无跳号，错表即停
- **Stage 1 黄金三章深拆**：前3章逐章深拆（开篇钩类型/信息释放顺序/第一个期待线/金手指亮相方式）；产出快速预览，**默认停靠问用户是否继续**；用户说"完整拆解/一次跑完"则不停
- **Stage 2 逐章摘要**：每章10-40个情节点（密度约150-200字/个，不足10按10）；每章带基调标注（枚举：热血/爽/虐/悬疑/温馨/压抑/愤怒/悲伤/紧张/平静）；**计数验证：摘要数==章节数**；失败重试1次，再失败标 `⚠️跳过` 不阻断
- **Stage 3 聚合分析**：先从摘要识别剧情大纲，再按大纲分配情节点；产出两份权威文件：`剧情/节奏.md`（信息推进/情绪触动点/爆发节奏）+ `剧情/情绪模块.md`（读者需求/情绪引擎/可复现模块卡）；角色去重+别名归一+分级（主角/核心配角/功能角色）
- **Stage 4 设定+关系**：世界观/势力体系；角色完整档案；关系提取**从情节点提取**（含演变追踪）
- **Stage 5 汇总报告**：写法技巧清单（一笔两用/延迟揭示/视角欺骗/对比锚点/行为循环/身体反应替代心理/跨章回扣）；**选题回填**：把已有 `选题决策.md` 里的"待拆文验证"改为带出处的"本书拆解支撑"
- **Stage 6 文风**：`文风.md`（句长/标点/对话潜台词/情绪交替周期+4-6段原文锚点范例+分层模仿建议，≤4000字）；失败不阻断

**质量阈值**：事实可溯源（等级/数值/出场章/谁说的话必须 grep 回原文，原文没给写"原文未明确"，禁推断填空）；聚合置信度≥0.85；情节覆盖率85%-95%；重叠率≤35%

## 短篇拆解管道（Stage 2-6 串行）

1. **题材识别**：13类关键词表（追妻火葬场/重生复仇/死人文学/小三/世情/豪门/宫斗宅斗/民俗/悬疑/甜宠/双男主/沙雕反套路/仙侠），识别结果写入元信息（下游写作依赖它选题材标尺）
2. **结构+情节节点**：功能分段4-6段（必含开端/发展/高潮/结局）；对话体/聊天记录/帖子体按时间/说话人切换/信息揭示点分段
3. **情感线+爆点**：情感曲线≥5节点；爆点6维度分析；期待感分析
4. **反转+写作手法**：反转铺垫≥2条；写作手法≥5项（POV/对话/时间/信息/其他）
5. **人物+开头结尾**：人物分类+功能标签；开头分析前50/100字；结尾收束检查
6. **综合评估**：五维评分+爆点性+话题性+**共鸣分析≥3层**+可复用结构≥3条+节奏速报

## 落盘结构

```
拆文库/{书名}/
├── 原文/          # 备份
├── 章节/          # 深度拆解+逐章摘要
├── 剧情/          # 节奏.md + 情绪模块.md
├── 角色/
├── 设定/
├── 拆文报告.md
├── 文风.md
└── _progress.md   # 断点续跑用（记录已完成Stage）
```

大书（>200章）分批：首期深拆前50章+全书概要，其余200字/章简化摘要，二期再补。
预期耗时提示给用户：<50章约30-60分钟；50-200章约1-3小时（多轮会话）。
