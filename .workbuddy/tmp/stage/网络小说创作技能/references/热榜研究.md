# 热榜研究手册（番茄热榜持续研究与能力升级系统）

> 触发：`热榜研究 / 研究热榜 / 更新知识库 / 留存分析 / 本章结构分析`。
> 定位：把"看热榜"变成可重复、可积累、可证伪的工程流程。产出只进《热榜知识库》，不直接改常量表——常量表数值仍按「八、修改约定」走，知识库提供证据。

## 一、研究样本协议

1. **覆盖面**：每轮至少 2 本**未研究过题材**的榜首/前三（都市、历史、玄幻、系统、重生、言情、悬疑、科幻、年代、乡土、灾难、无限流、灵异、官场、商战…轮转补位）；同一题材至少 2 本才能下 B 类结论，1 本只能记 C 类。
2. **选样标准**：在读数优先（≥30万），连载/完结均可；完结书补"结局阶段"证据，连载书补"最近章"证据。
3. **禁止**：只看简介/第一章下结论；把单本书个性当规律（那是 C 类）。

## 二、章节采样协议（每本必做）

网页免费深度通常 ≈10-19 章（按书浮动），过期章节只剩**预览段 + 官方字数 + 章名**。因此固定双层采样：

| 层 | 采样点 | 能拿到什么 |
|----|--------|-----------|
| 全文层 | 第 1/2/3/5/10/15/19 章（前5、前10、前20 三个梯次 + 中前期） | 结构统计 + 开头结尾 + 手法 |
| 全书层 | 全书 25% / 50% / 75% / 最后章（预览页） | 官方字数趋势 + 章名演进 + 开头形态 |

**前—中—后对照必答七问**：各阶段字数变没变？冲突密度变没变？爽点/悬念/信息释放方式变没变？中期靠什么防疲软？后期主线如何升级？最近章是否松垮？第一章到底写了什么（逐句）。

**取证纪律**（沿用字体反爬教训）：DOM 文本只用于结构统计（段落/长度/引号占比），**字面结论（引导语形态、反应行、断章形态）必须截图肉眼核验**，每轮≥3 张；官方字数以页面「N字」为准。

## 三、工程化拆解模板（每本重点书≥3章全链）

对每章建立数据链「章节→场景→冲突→爽点→信息→悬念→结果→下章钩子」：

```
第X章
- 本章目标（视角人物要什么）：
- 主要冲突（谁vs谁/什么，升级了吗）：
- 最大爽点（来源类型 + 落点动作/对话）：
- 新增信息（读者新知道了什么）：
- 隐藏信息（故意不给什么）：
- 情绪变化（起点→终点）：
- 人物变化（关系/地位/能力位移）：
- 伏笔（埋/推进/回收，编号）：
- 章末钩子（形态 + 载体-动作-对象指纹）：
- 本章字数（官方）：
- 节奏强度（快/中/慢 + 依据）：
- 对下一章的推动（不写下一章会断在哪）：
```

## 四、三轮复盘制

- **第一遍**：按二、三采集，回答七问，填数据链。
- **第二遍**：回看同一批章，专找第一遍遗漏——伏笔位置与回收距离、信息差三层（作者/主角/配角/读者）、爽点间隔、人物标签建立事件、章节模板重复度。
- **第三遍**：把观察翻译成**可执行规则**（能写进校验/审稿卡的话），每条标注：A类（≥3本跨题材验证）/ B类（单一题材≥2本）/ C类（单本个性，只取底层原理）。

## 五、横向比较与转化纪律

- **A类 → 修常量表/SKILL 规则**（走常量表「八、修改约定」）；
- **B类 → 写进知识库题材卡，书格机制引用**；
- **C类 → 知识库记原理不记皮相**（例：戏神【面板】断章的原理是"章末信息具象化"，不是抄面板）。
- **禁止**复制任何作者的具体句子、设定、桥段、标志性写法；研究的是机制。

## 六、知识库更新与迭代输出（每轮必做）

按《热榜知识库》十五类归位；与旧规则对比后，每轮输出一节「轮次记录」：

```
【轮次N · 日期 · 样本】
【本轮新增规律】…
【被验证的旧规律】…
【被修正/推翻的旧规律】…（写明推翻证据）
【新的章节/开篇/爽点/悬念/章末模板】…
【新的避坑规则】…
【对现有写法的修改建议】…（哪些进了常量表/SKILL，哪些留给书格）
```

## 七、量化检查（写章侧消费）

- 每章交付前跑 `scripts/retention_check.py`（本章结构分析 + 留存风险，建议级，配合 check_chapter.py 与审稿卡）；
- 跨章信号（节奏类型连续、爽点间隔）归 `grep_consistency.py` D 类与体检，不在单章重复。

## 八、已知平台取证事实（复用时不再踩坑）

- 网页免费深度≈10-19 章/书（浮动）；过期章 reader 只渲染预览段，**官方字数仍全量可见**；
- 正文容器 `.muye-reader-content`，滚动容器 `.muye-reader`（window 滚动无效）；
- 章节页 DOM 常双份渲染：段数按半读，比率类指标不受影响；
- 榜单 URL：`/rank/1_2_*`=男频、`/rank/0_2_*`=女频（1140仙侠/1014高武/751悬疑灵异/262都市脑洞/272历史脑洞/257玄幻脑洞/79年代/8科幻末世/1139古风世情/1017民国言情…）。
