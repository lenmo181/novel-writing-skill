# 短篇模式手册

> 触发：用户说"写短篇/知乎盐选/番茄短篇/短故事"，或作品字数 <1.5万字。
> 主文件的禁言词、Show don't tell、活人感、反AI规则全部适用；字数/对话占比校验用 `--min/--max` 按目标字数跑。

## 字数与结构硬参数

- **路由阈值**：<1.5万字走短篇；1.5-2万灰区问用户；>2万建议转长篇
- **默认字数**：8000-20000（用户指定优先）
- **功能分段**：4-6段，必须含 开端/发展/高潮/结局
- **节数硬约束**：正文节数 = 小节大纲规划节数，不得合并省略
- **每节职责**：围绕一个主问题，让风险/信息/关系/资源/决定/行动/读者理解至少一项发生可见变化；办事被卡必须卡出信息/关系/代价/选择/伏笔变化
- **情感曲线**：≥5个节点（含起点状态和终点状态）
- **反转铺垫**：≥2条（反转型的必须前后能指认）

## 叙事铁律

- **开头3句定生死，结尾定传播**（完读率=情绪拉扯到位；转发率=有共鸣/反转/余韵）
- 一个核心支点撑一篇：反转型围绕一次主揭示蓄力；无反转型围绕报应兑现或甜度递进
- 每句话必须有用：不推动剧情、不铺垫反转、不推高情绪 → 删
- **默认第一人称**（更沉浸；知乎/女频尤其）
- 不用反转就必须用强共鸣/强话题/强余韵补足传播风险

## 六种情绪目标（开篇先定一个）

| 情绪目标 | 常配题材 | 难度 |
|---------|---------|------|
| 爽感释放 | 打脸逆袭/战神 | 低 |
| 反转震撼 | 悬疑/身份错位 | 高 |
| 意难平 | 虐恋/遗憾/追妻火葬场 | 中 |
| 治愈温暖 | 成长/亲情/团宠 | 中 |
| 细思极恐 | 悬疑心理/民俗 | 高 |
| 共鸣感动 | 现实/职场/婚姻 | 中 |

## 核心题材风格包（10类，定题材即切腔调）

追妻火葬场（含现代/古代/民国变体，分支：小三文学/死人文学）、世情打脸、复仇打脸、总裁豪门、宅斗宫斗、民俗怪谈、悬疑、甜宠、双男主、沙雕脑洞（弹幕/系统反套路）。每包决定：开篇切入/钩子密度/情绪烈度/对话金句风/收尾方式。

## 投稿层知识（按目标平台定基调）

- **知乎盐选**：第一人称剥洋葱式，细思极恐，章末颠覆认知；可用「」引号；导语=前150-220字四维骨架（起因+核心冲突+人设底色+情绪反转），黄金三角=具体物件+信息差+留白钩子各落在哪句
- **小程序短篇**：开局即地狱、当众打脸、卡脖子断点，节奏最快
- **番茄短篇**：顺滑无毒、金手指直白、大满贯收尾
- **七猫短篇**：1-2万字7-19章，完读率导向，女性读者80%+
- 付费点/最强断点优先卡在中段章末，且断点前后剧情点密度必须递增

## 格式规范（最高优先级）

- 正文单文件 `正文.md`
- 相邻段落间**只允许一个换行符**（无空行）
- 小节标记全文统一：`###1.` `###2.` …
- 引号：默认半角双引号（与长篇弯引号规则不同！），盐选平台可用「」
- 校验脚本对短篇用 `--min 8000 --max 20000 --quote straight`（盐选加 `--quote any`），引号检查与对话占比统计同源切换

## 四阶段流程

1. **定情绪目标**（上表选一个，和用户确认题材包）
2. **构思核心框架**：核心支点+反转/兑现设计+小节大纲（含每节职责）→ 用户确认
3. **逐节写作**：每节完自检"可见变化"清单；比喻词（像/好像/仿佛/如同）不成片堆叠，超10处逐处复核功能
4. **精修**：跑脚本（引号口径 `--quote straight`，盐选用 `--quote any`）+ **8 Gate** 过一遍 + 结尾余韵检查
