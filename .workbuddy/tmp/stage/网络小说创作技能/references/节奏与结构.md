# 节奏与结构手册（冲突值 · 章节类型 · 伏笔生命周期）

> 触发：`标注章节类型 / 算冲突值 / 节奏诊断 / 这卷节奏是不是有问题`。
> 配套脚本：`scripts/conflict_score.py`（算值与排章建议）。数值真源见 `references/常量表.md`。
> 本手册只解决"量化与标注"，不替代写作手艺——正文怎么写仍看长篇模式手册与主文件写作铁律。

---

## 一、冲突值（事件量级的刻度尺）

### 1.1 算法

```
冲突值 = 基础分 1 + Σ(因子权重 × 该因子触发次数)
```

### 1.2 因子权重表（与 `scripts/conflict_score.py` 1:1）

| 因子 | 权重 | 触发口径（满足即计，可多次叠加） |
|------|------|--------------------------------|
| 核心角色状态根本性改变 | **+8** | 生死、境界跃迁、身份翻转、立场倒戈、关系本质逆转等**不可回退**的状态变更 |
| Tier-1 战略级伏笔回收或埋设 | **+8** | 与主线核心或结局直接相关的伏笔被埋下或回收 |
| Tier-2 战役级伏笔回收或埋设 | **+5** | 与当前卷/当前单元事件相关的伏笔被埋下或回收 |
| 破格事件 | **+5** | 超出常态规则、打破读者既有预期框架的事件（详见 §5） |
| 重要实体（组织/物品）状态改变 | **+3** | 宗门覆灭、阵营易主、关键信物易手或损毁 |
| 核心角色参与 | **+2 / 位** | 本章有实质性戏份的核心角色（主角、核心配角），每位 +2 |

> **不计分项**：场景转换、日常对话、氛围描写、次要角色出场——它们决定"好不好看"，不决定"量级多大"。

### 1.3 星级映射

| 分值区间 | 星级 | 档位名 | 排章含义 |
|----------|------|--------|---------|
| 分 < 5 | ★☆☆☆☆ | 日常 | 常规过渡，可作缓冲 |
| 5 ≤ 分 < 8 | ★★☆☆☆ | 推进 | 主线正常前进 |
| 8 ≤ 分 < 12 | ★★★☆☆ | 节点 | 单元内小高潮，可作为单元收束 |
| 12 ≤ 分 < 16 | ★★★★☆ | **峰值** | 本单元/本卷情绪高点，受峰值禁区约束 |
| 分 ≥ 16 | ★★★★★ | 核心峰值 | 全书级高点，卷末/大转折专用，一卷 1-2 次足够 |

### 1.4 三个算例

**算例一：日常缓冲章（茶馆递线索）**
> 主角与一位配角在茶馆交换情报，揭示一条 T3 战术线索，无状态变更。

```
基础 1 + 核心角色参与（主角）= 2  → 合计 3 分 → ★☆☆☆☆
```
结论：日常档，可作「缓冲-线索」章。

**算例二：单元内小高潮（擂台胜宿敌）**
> 主角擂台上击败宿敌，宿敌当众退场（核心反派状态根本性改变），关键信物易主。

```
基础 1 + 核心角色状态根本性改变（宿敌退场）+8
      + 重要实体状态改变（信物易主）+3
      + 核心角色参与（主角、宿敌）+4
= 16 分 → ★★★★★
```
结论：`1+8+3+4 = 16` 已顶到核心峰值。**若只想做成单元高潮，应拆分**：本场只留"胜擂+信物易主"，宿敌退场另排一章——拆分后 `1+3+4 = 8 分 → ★★★☆☆ 节点`（脚本 `--demo` 的「拆分版」即此数）。否则整卷高潮被提前用掉。

**算例三：卷末核心峰值（突破 + 战略伏笔回收）**
> 主角突破境界（不可回退），回收埋了整卷的 T1 战略伏笔，触发破格事件，四位核心角色同场。

```
基础 1 + 核心角色状态根本性改变 +8
      + T1 战略伏笔回收 +8
      + 破格事件 +5
      + 核心角色参与（4 位）+8
= 30 分 → ★★★★★
```
结论：卷末核心峰值。**同卷内不得再出现第二次同量级章**，否则峰值通胀、读者脱敏。

### 1.5 使用纪律（重要）

- **冲突值只用于事后标注与体检**：算完记进章纲/章节目录的"冲突值"列，用于检查节奏分布与峰值间距。
- **严禁为提分而新增死亡/暴力/黑化事件**。分值低不是缺陷——日常章、缓冲章本来就该低分；为了让数字好看去加刑、加死人、加黑化，是把工具用反。
- 一切事件仍受 SKILL.md《平台审核红线》约束，**冲突值不构成任何放宽理由**。
- **冲突值 ≠ 爽点强度**：
  - 冲突值衡量**事件量级**（世界状态改变了多少）；
  - 爽点强度衡量**读者情绪**（读者爽到了多少）。
  - 二者**不可互推、不可互替**：一场大战（高冲突值）可能是憋屈的惨胜，毫无爽感；一次当众打脸（低冲突值）可能爽到极点。写章时"量级"与"情绪"分开设计，先定量级再定情绪落点。

## 二、章节节奏类型（章纲必标）

**枚举白名单（只有这六种，不得自造）**：

| 类型 | 职责 | 渲染重心 |
|------|------|---------|
| **主线** | 推进主线目标/事件链 | 事件推进 + 冲突升级 |
| **峰值** | 单元/卷的情绪高点 | 动作、场面、结果落点（压缩心理与对话） |
| **缓冲-对话** | 关系演变 + 潜台词 | 对话本身即内容，删掉对话剧情受损 |
| **缓冲-线索** | 伏笔与信息推进 | 信息揭示 + 谜面加码 |
| **缓冲-代价** | 清算前文增益的代价 | 代价的具象（身体/资源/关系/名声） |
| **校准** | 校正前文偏差、补漏、调关系 | 补齐与收束，不新增主线负担 |

**章纲标注要求**：每章条目必须写明节奏类型；写正文前据类型决定渲染重心；写完自检是否跑偏（峰值章写成心理独白大段 = 跑偏）。

### 2.1 三种缓冲章怎么写

**缓冲-对话**
- 内容标准：关系确实发生演变（更近/更远/更暧昧/更提防），且对话带潜台词——读者读出的话比字面多。
- 判定线：把本章对话整段删掉，如果主线毫发无伤 → 说明它没在演关系，是水文，重写。
- 禁止：无冲突的纯闲聊、重复交代已交代过的信息。

**缓冲-线索**
- 内容标准：推进伏笔或揭示信息，**单章揭示信息量不超过该线总量的 30%**（见 §4）。
- 判定线：本章结束后，读者至少多知道一件"会被用到"的事，或多出一个新问号。
- 禁止：一次性把线索讲完（把后面的高潮提前烧掉）。

**缓冲-代价**
- 内容标准：清算前文增益的代价——赢来的东西开始收账（旧伤复发、资源见底、树敌、名声反噬）。
- **兑现窗口：必须在对应增益出现后的 1-5 章内落地**。超窗未兑现 → 增益变白嫖，金手指四原则里的"有代价"失效。
- 判定线：本章结束，读者感受到"他上一次赢得不轻松"。

### 2.2 缓冲章 ≠ 无爽点章（硬下限）

- **任意连续 2 章必须有至少 1 个爽点或明显期待线推进。** 这是硬下限，缓冲章也不例外。
- 允许的"缓冲期写法"：爽点可以不来，期待线不能断——用打脸预告、身份悬念、目标牵引、危机倒计时任一条撑住翻页率。
- **缓冲比是软指标**：基准 25%（其中 20% 可用缓冲 + 5% 校准章），**仅体检提示，不熔断**。缓冲比偏高不判失败，只在体检报告里提示"缓冲占比偏高，注意追读风险"。

## 三、峰值禁区与宏观节奏

### 3.1 峰值禁区（排章纲的硬约束）

**冲突值 ≥ ★★★★☆（分值 ≥12）的章 = 峰值章。峰值章前后各 2 章内，不得排「缓冲-对话」。**

原因：峰值章刚把情绪拉满，紧接一段轻飘飘的闲聊会把势能泄掉；读者刚从高潮出来，需要的是"余韵型推进"或"代价清算"，不是关系闲谈。

替代排法：峰值章前后优先排「缓冲-代价」（高潮的账单）或「主线」（顺势推进），把「缓冲-对话」挪到离峰值 ≥3 章的位置。

### 3.2 宏观节奏 20:30:30:20（以卷为单位）

起（20%）: 承（30%）: 转（30%）: 合（20%）——**以整卷章数为单位统计，不是单章字数比例**。

| 段落 | 占比 | 内容职责 |
|------|------|---------|
| 起 | 20% | 立本卷目标、抛本卷核心问题、铺新伏笔 |
| 承 | 30% | 推进与受阻交替，关系与信息逐步展开 |
| 转 | 30% | 主线反转、最大危机前压、代价集中清算 |
| 合 | 20% | 高潮兑现、伏笔回收、卷末钩子 |

### 3.3 卷内里程碑（与「爽点黄金节奏」的关系）

- **20% 处**：第一个中爽点
- **50% 处**：主线反转
- **80% 处**：最大危机
- **卷末**：大爽点 + 卷末钩子

**与主文件「爽点黄金节奏」的关系**：两者是**同一套里程碑的两种表述**——主文件写的是"卷内节奏第1章黄金开篇 → 20%第一个中爽点 → 50%主线反转 → 80%最大危机 → 卷末大爽点+钩子"；本手册补的是"这些里程碑该怎么用冲突值校验"：20%处冲突值应达到 ★★★☆☆ 以上，80%处应达到 ★★★★☆ 以上。**不是两套标准，是一套标准的定性/定量两面。**

## 四、伏笔 Tier 生命周期与信息分级

### 4.1 Tier 分级

| Tier | 名称 | 挂靠对象 | 沉睡阈值 | 回收窗口 |
|------|------|---------|---------|---------|
| **T1** | 战略级 | 主线核心、结局、主角根本身份 | 卷末审计 | 跨卷，通常在书的中后段 |
| **T2** | 战役级 | 当前卷 / 当前 10 万字单元 | 30-40 章 | 本卷内 |
| **T3** | 战术级 | 当前章 / 近场事件 | 15-20 章 | 数章内 |

### 4.2 生命周期四态

`埋设 → 沉睡 → 推进 → 回收`（外加终态 `废弃`）

- **埋设**：写进伏笔追踪表，登记编号 + Tier + 预计回收章。
- **沉睡**：超过该 Tier 沉睡阈值未被推进 → **体检告警**（不是错误，是提醒："这条线读者已经忘了"）。
- **推进**：每次推进在章纲标注伏笔编号，单章推进不超过该线总量的 30%。
- **回收**：回收时更新追踪表状态，计入回收率。

### 4.3 回收率软目标

| 指标 | 目标 | 说明 |
|------|------|------|
| 核心伏笔回收率 | ≥80% | 全书口径，T1+T2 计入 |
| 跨卷回收率 | ≥60% | 跨卷埋设的伏笔中按期回收的比例 |

均为**软目标**，由体检跟踪提示，不做单章硬卡。

### 4.4 子链周期

一条支线期待线的最长牵引周期 **30-40 章**，且**必须 ≥ 该支线所属 Tier 的沉睡阈值**。T1 战略线随卷长走，不受 30-40 限制，但每卷末必须审计一次。

### 4.5 信息分级与单章解密上限

| 信息等级 | 内容 | 单章揭示上限 |
|---------|------|-------------|
| A 级（核心谜底） | 身份真相、结局要素、金手指来源 | 单章 ≤1 条，且不得早于章纲计划章 |
| B 级（推进信息） | 势力动向、线索指向、人物动机 | 单章 ≤3 条 |
| C 级（细节信息） | 环境、习俗、次要关系 | 不限，但不得挤占 A/B 的篇幅 |

**总上限：单章信息解密量 ≤ 该线/该谜底总信息量的 30%。** 超过即"一次性倒完"，后续无牌可打。

## 五、破格事件与配额

**破格事件**：超出常态规则、打破读者既有预期框架的事件（例：一直在装弱的主角当众亮出真实身份；既定阵营格局被第三方掀翻）。

| 约束 | 内容 |
|------|------|
| 配额 | **每卷 ≤3 次** |
| 边界 | 破格**不得突破角色核心烙印**——核心驱动力（他为什么活着）、根本缺陷（他栽在哪）、绝对红线（他死也不做的事）不得为破格而改写 |
| 理由 | 破格是稀缺资源，用一次少一次；突破烙印等于换了个角色，读者会判定"人设崩" |
| 计分 | 每次破格 +5 冲突值 |

## 六、场景呼吸拍

**一个场景的基本呼吸：展示 → 思考 → 对话 → 行动**（循环推进，不必四拍齐全，但不得只剩其中一拍）。

| 章节类型 | 呼吸拍配比要求 |
|---------|--------------|
| 峰值章 | **「思考 + 对话」合计占比 ≤10%**——把心理活动与对话压到最低，靠动作与场面推进 |
| 缓冲-代价章 | 聚焦**思考 + 展示**——代价是"慢慢渗出来的"，靠具象细节和内心消化，不靠台词解释 |
| 主线章 | 四拍均衡，展示与对话为主 |
| 缓冲-对话章 | 对话为主（≥60%），展示辅助 |
| 缓冲-线索章 | 展示 + 对话并重，思考少量用于拼图 |
| 校准章 | 展示为主，对话用于补齐信息 |

**禁用**：整场只有"思考+展示"的静态独白段（那是散文，不是网文）；整场只有对话不停歇的答问机（那是剧本大纲，不是小说）。

## 七、体检提示（仅一句，不做独立机制）

- 若**一个单元剧窗口内新实体暴涨且缓冲章不足**（例：连续多章密集抛出组织/人物/物品而几乎无缓冲章消化），体检报告中提示一句「新实体增速超过消化速度，建议插入缓冲-线索章或合并实体」——**仅作提示，不设阈值熔断、不建独立检测机制**。
