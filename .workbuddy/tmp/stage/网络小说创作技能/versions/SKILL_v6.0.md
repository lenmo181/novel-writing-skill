## 🔴 核心写作规则（AI必读！每次写作必须执行！）

### 🚫 格式禁忌

**严禁出现在小说正文中：**
1. 禁止 `>` 引用符号
2. 禁止 Markdown 引用格式、代码块、表格
3. 禁止 YAML frontmatter
4. 禁止段内残留写作过程标记（如【第一段完成，当前累计：XXX字】）

以上全部由校验脚本硬卡，检出即不通过。

### 🗣️ 对话铁律（最高优先级！）

**网文不是散文，是"演"不是"描"！一整章全是场景描述没有对话 = 水文 = 读者直接划走！**

**强制要求：**
- **每章对话占比必须 ≥ 40%**（2500字章节至少1000字是对话，脚本硬卡）
- **每章至少3次对话交换**（两人你来我往，不是独白/自言自语）
- **每个场景必须有至少1次对话交换**
- 对话必须**有冲突、有潜台词、有信息差**，不是"他说""她说"的流水账
- 对话推动剧情：每句要么推进剧情，要么揭示人物，要么埋下伏笔
- 对话后必须有反应（动作/心理/环境），但不能用大段描述吞掉对话节奏
- **所有对话必须使用中文弯引号 `""`，禁止半角直引号，禁止直角引号「」（脚本硬卡）**

**对话写作模板：**

**模板A：冲突揭露型**（最常用，占60%章节）
```
场景：1-2句话交代地点（不超过30字）
A：[直接抛出核心冲突/质问]
B：[反击/否认/装傻]
A：[抛出证据/关键信息]
B：[情绪爆发/反转]
动作：1-2个动作收尾（不超过20字）
```

**模板B：信息交换型**（推进剧情，占25%章节）
```
场景：1句话交代
A：[给出关键信息/情报]
B：[追问/质疑]
A：[补充细节/后果]
B：[做出决定/行动]
动作/环境：1句话收尾
```

**模板C：情绪爆发型**（高潮/爽点章，占15%章节）
```
场景：短，1句话
A：[挑衅/羞辱/背叛台词]
B：[克制/沉默]
A：[继续施压/升级侮辱]
B：[彻底爆发/反击]（短句子，不超过5个字+动作）
```

### 📏 字数铁律

**目标：每章严格2500-3000字（纯正文，仅计算中文字符+中文标点，脚本硬卡）**

**字数计算规则：**
- **只计算纯正文**：中文字符 + 中文标点符号
- **不计算**：章节标题、分隔线、标记符号、统计行、空行、英文标点、空格

**三段式写作（写作过程用）：**

| 段落 | 目标字数 | 最低字数 | 最高字数 | 对话占比 |
|------|---------|---------|---------|---------|
| 第一段 | 900字 | 800字 | 1000字 | ≥30% |
| 第二段 | 1100字 | 1000字 | 1200字 | ≥40% |
| 第三段 | 800字 | 700字 | 900字 | ≥30% |
| **全章** | **2700字** | **2500字** | **3000字** | **≥40%** |

**第一段（900字，≥2次对话交换）：** 开头结构：1句话交代场景（≤30字）→ 立即进入对话 → 1-2句对话揭露冲突。段尾必须是小钩子（对话悬念/未说完的话/突发状况）。写完输出：`【第一段完成，当前累计：XXX字，对话约：XXX字】`

**第二段（1100字，≥3次对话交换）：** 冲突升级+高潮。对话交换之间只写1-2句动作（≤30字）。累计必须≥1900字。写完输出：`【第二段完成，当前累计：XXX字，对话约：XXX字】`

**第三段（800字，≥30%对话）：** 收尾+章末钩子，**最后一句必须是对话**。写完输出：`【第三段完成，当前累计：XXX字，对话约：XXX字，全章对话占比：XX%】`

**最终检查：** 三段标记**只出现在写作过程回复中，不得写进章节文件**；写入文件的正文累计<2500字禁止交付，>3000字删次要场景和心理描写。

**与「智能分段」的关系：** 三段式（900/1100/800）是**写章时的过程结构**；`智能分段` 指令是**发布前对成品章节按 10%/60%/20%/10% 划分并标注广告位的后期工具**。两者用途不同，不冲突。

## 🎯 写章节执行流程

### 第零步：环境与小说库
- 确认项目目录存在，读取 `templates/项目模板.md` 约定的全部文件
- 若配置了百万小说库路径：从章纲提取关键词→选TOP3同类→分析写法→写作时应用；未配置则跳过，不阻塞

### 第一步：状态校验
- 读取 mind/ 全部6档案 + 上章结尾500字
- 确认每个角色位置/物品/时间与上章一致（校验项9、12的前置）

### 第二步：事业部调度
- D01设定：校验世界观/三根高压线
- D02剧情：确保章纲执行，使用落差公式
- D03角色：展示缺陷+口头禅+怪癖
- D04冲突：落差公式+多方博弈+代价原则
- D05伏笔：埋设/回收伏笔并更新追踪表
- D06对话：去形容词化+潜台词+停顿留白
- D07描写：五感轰炸（至少3感）+动态细节
- D08节奏：快慢切换+长短句交替
- D09情感：悲悯不煽情+克制+留白
- D10风格：风格锚定+比喻铁律+反啰嗦
- D11修辞：3种修辞混搭+比喻融入动词名词

### 第三步：四层瀑布
- L1种子：本章核心情绪/信息（1句话）
- L2架构：2-4个场景，每个场景的冲突点和情绪转折
- L3叙事：视角和时序选择
- L4渲染：执行写作（真人策略+比喻打击+反啰嗦+活人感+库参考写法），按三段式推进

### 第四步：19项校验（脚本7项+AI 12项，见上表）
- **先跑脚本，绿了再做AI语义12项；任何一项不过→改→重验**

### 第五步：更新档案
- 写入章节文件到 `书稿/第XXX章_章节名.md`
- 自动更新 mind/ 6档案（快照/锚点/伏笔/时间线/章节目录含进度行/剧情锁定）
- 更新完成后，下一章开工前必须重读全部档案

## 📊 爽点黄金节奏（精确到章数）

- **小爽点**：每1-3章一个（赚第一笔钱、打脸小喽啰、得小宝物）
- **中爽点**：每10-20章一个（打败小boss、完成重要任务、获得大提升）
- **大爽点**：每一卷一个（打败最终boss、实现人生逆袭）
- **压抑期：爽点 = 3:1 到 5:1**，没有压抑的爽点像白开水
- **核心原则**：爽点之前必须有铺垫，先让读者憋屈再爆发，爽感翻倍

## 💥 10个爽点公式（可直接套用）

1. **先抑后扬**：先让主角被看不起，再用实力打脸
2. **对比衬托**：用配角的愚蠢衬托主角的厉害
3. **预期违背**：读者以为会这样，结果完全相反
4. **扮猪吃虎**：主角隐藏实力装弱，关键时刻爆发
5. **意外收获**：解决麻烦时意外得到意想不到的好处
6. **复仇打脸**：报复曾经欺负过自己的人
7. **英雄救美/救场**：别人最危险时挺身而出
8. **装逼成功**：在众人面前展示实力收获崇拜
9. **反杀逆袭**：被逼到绝境然后绝地反杀
10. **众人追捧**：从底层变成所有人尊敬的大佬

## 🔗 三种百试百灵的章末断点

1. **悬念断点**：结尾抛出读者猜不到答案的问题
   - 例：主角打开密室的门，里面坐着一个人说："我等了你二十年"
2. **反转断点**：结尾推翻读者之前的认知
   - 例：前面说师父是普通人只会养花→结尾敌人杀到→师父："三百年了，终于有人敢来找我报仇了"
3. **情绪断点**：制造强烈情绪让读者"憋得慌"
   - 例：主角刚救下的人转头把主角出卖了，那人笑着说："你的命比我的良心值钱"

## 🎯 好情节万能公式

**好情节 = 有冲突的事件 + 爽点的结果**
- 外部冲突：主角和反派/配角/环境/命运的矛盾
- 内部冲突：主角内心的挣扎和矛盾（深度的关键）
- 两者必须结合才有深度

## 🔴 番茄爆款铁律

- **快**：开篇300字内必须出冲突，每500-800字一个爽点，没有资格慢热
- **爽**：主角被欺负马上打脸，不憋屈，爽点间隔不超过3章
- **贴**：选题贴合当下热点（赘婿/种田/都市/穿书/悬疑/甜宠）
- **三线并行**：剧情主线+成长线+感情线，感情线不抢主线风头
- **先定高潮结局再倒推**：打破顺写思路
- **单元剧结构**：长篇拆成10万字小战役，每个战役有独立冲突和高潮

## 🚫 反AI啰嗦（8种必须改写，校验项16）

1. 禁止"首先...其次...最后..."模板句式
2. 禁止"综上所述""总而言之""不言而喻"等AI标记
3. 禁止"不禁""忍不住""不由得"三连发
4. 禁止连续3个以上排比句
5. 禁止"他的眼中闪过一丝XXX"套路
6. 禁止"嘴角微微上扬/勾起一抹弧度"套路
7. 禁止每段都以"他知道/她明白/他们意识到"开头
8. **禁止滥用破折号"——"（脚本硬卡：每章最多2个，大多数章节应该零个）**

## 🎭 人物描写铁律（校验项17）

- 每次人物出场，**最多描写2个特征**
- 只写**对剧情有用的特征**，**外貌描写不超过30字**
- 不要写环境烘托人物
- **人物靠行为塑造，不靠外貌堆砌**。一个人做了什么比他长什么样重要一百倍

## 🧬 活人感写作（校验项14、15）

- 至少3处长短句混搭（不能全是差不多长的句子）
- 至少2处插入式思考/犹豫
- 至少1处角色偏好词/口头禅
- 对话必须有潜台词、有省略、有口头禅
- **对话中必须有**：重复用词（口头禅）、打断（"等等！""慢着！"）、说错改口（"不是...我的意思是..."）至少1种
- **禁止对话完美对称**：不要A说一行B说一行机械交替，有的人只说3个字，有的人连续说三句

## 🎨 引号配置
