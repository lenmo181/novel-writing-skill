## 🔴 核心写作规则（AI必读！每次写作必须执行！）

### 🚫 格式禁忌

严禁出现在小说正文中（脚本硬卡）：
1. 禁止 `>` 引用符号、Markdown 引用格式、代码块、表格
2. 禁止 YAML frontmatter
3. 禁止段内残留写作过程标记（如【第一段完成，当前累计：XXX字】）

### 🗣️ 对话铁律（最高优先级！）

**网文不是散文，是"演"不是"描"！一整章全是场景描述没有对话 = 水文 = 读者直接划走！**

**强制要求：**
- **每章对话占比必须 ≥ 40%**（脚本硬卡）
- **每章至少3次对话交换**（你来我往，不是独白/自言自语）
- **每个场景必须有至少1次对话交换**
- 对话必须**有冲突、有潜台词、有信息差**，不是"他说""她说"的流水账
- 对话推动剧情：每句要么推进剧情，要么揭示人物，要么埋下伏笔
- 对话后必须有反应（动作/心理/环境），但不能用大段描述吞掉对话节奏
- **所有对话必须使用中文弯引号 `""`，禁止半角直引号，禁止直角引号「」（脚本硬卡）**

**对话写作模板：**

**模板A：冲突揭露型**（最常用，占60%章节）
```
场景：1-2句话交代地点（不超过30字）
A：[直接抛出核心冲突/质问]
B：[反击/否认/装傻]
A：[抛出证据/关键信息]
B：[情绪爆发/反转]
动作：1-2个动作收尾（不超过20字）
```

**模板B：信息交换型**（推进剧情，占25%章节）
```
场景：1句话交代
A：[给出关键信息/情报]
B：[追问/质疑]
A：[补充细节/后果]
B：[做出决定/行动]
动作/环境：1句话收尾
```

**模板C：情绪爆发型**（高潮/爽点章，占15%章节）
```
场景：短，1句话
A：[挑衅/羞辱/背叛台词]
B：[克制/沉默]
A：[继续施压/升级侮辱]
B：[彻底爆发/反击]（短句子，不超过5个字+动作）
```

**对话提示语多样性（v6.1）：**
- 说道/问道/答道类提示语**每章合计≤10次**（脚本警告）
- 提示语轮换四式：**动作beat替代**（"他放下筷子。"）→ **前置** → **后置** → **省略**（对答清晰时裸对话）
- 禁止连续3句使用同一提示语模式

### 📏 字数铁律

**目标：每章严格2500-3000字（纯正文，仅计算中文字符+中文标点，脚本硬卡）**

**三段式写作（写作过程用）：**

| 段落 | 目标字数 | 最低字数 | 最高字数 | 对话占比 |
|------|---------|---------|---------|---------|
| 第一段 | 900字 | 800字 | 1000字 | ≥30% |
| 第二段 | 1100字 | 1000字 | 1200字 | ≥40% |
| 第三段 | 800字 | 700字 | 900字 | ≥30% |
| **全章** | **2700字** | **2500字** | **3000字** | **≥40%** |

**第一段（900字，≥2次对话交换）：** 1句话交代场景（≤30字）→ 立即进入对话 → 1-2句对话揭露冲突。段尾必须是小钩子。写完输出：`【第一段完成，当前累计：XXX字，对话约：XXX字】`

**第二段（1100字，≥3次对话交换）：** 冲突升级+高潮。对话间只写1-2句动作（≤30字）。累计必须≥1900字。写完输出：`【第二段完成，当前累计：XXX字，对话约：XXX字】`

**第三段（800字，≥30%对话）：** 收尾+章末钩子，**最后一句必须是对话**。写完输出：`【第三段完成，当前累计：XXX字，对话约：XXX字，全章对话占比：XX%】`

**最终检查：** 三段标记只出现在写作过程回复中，**不得写进章节文件**；正文<2500字禁止交付，>3000字删次要场景和心理描写。

**与「智能分段」的关系：** 三段式（900/1100/800）是**写章时的过程结构**；`智能分段` 是**发布前按10%/60%/20%/10%划分广告位的后期工具**。两者用途不同，不冲突。

## 🥇 黄金开篇铁律（v6.1）

**前三章任务（推荐位生死线）：**

| 章 | 必须完成 |
|----|---------|
| 第1章 | 主角出场 + 异常事件/核心冲突亮相 + 金手指或悬念露头 |
| 第2章 | 金手指第一次小规模演示 + 近期目标确立 + 第一个爽点或打脸预告 |
| 第3章 | 第一个完整爽点闭环（打脸/收益），读者拿到第一次满足 |

**前300字手术标准：** 第一屏必须出现**人物+异常**。第一句禁止天气、景色、时间交代。

**禁开头清单（AI最常见的废开头，出现即重写）：**
1. 天气/景色描写开场
2. 做梦/梦醒
3. "XX睁开眼"式醒来
4. 照镜子/自视外貌
5. 大段回忆/身世倒叙
6. 世界观/势力/历史解说
7. 无事件的纯对话
8. 主角日常流水账

**自检：删掉第一段，故事是否直接受损？不受损就删。**

## 🎣 期待感体系（v6.1）

爽点=即时兑现；期待感=延迟兑现，是真正的翻页引擎。**每章必须让以下至少一条被制造或被推进（校验项24）：**

1. **打脸预告**：读者知道主角有底牌，场内配角不知道→等爆发
2. **身份悬念**：主角/关键角色的真实身份、来历、目的吊着读者
3. **目标牵引**：明确的近期目标+差距感（夺回东西/三日后比武/差一颗丹药）
4. **危机倒计时**：明确的时间/资源压力

**信息差管理：** 关键信息分三层——**读者知道/主角知道/配角知道**。打脸爽感=信息差套利（读者比场内配角知道得多）。写每章前明确三层知情范围，写完更新快照"知情"字段。

## 🎥 视角纪律（v6.1，校验项25）

- 默认**第三人称单主角限知视角**，用户指定第一人称除外
- **一章内禁止切换视角**：镜头跟谁，就只写谁看到的、谁想到的
- 禁上帝剧透："他不知道的是……"全章最多1次，且必须服务章末钩子
- 多视角戏用空行分场，每场内仍单视角

## 🎭 Show don't tell（v6.1，校验项26）

- **禁止直贴情绪标签**：不写"他很愤怒/她感到悲伤"，写行为、生理反应、动作：
  - 愤怒 → 他把杯子放下的时候，重了那么一点
  - 紧张 → 他数到第三次楼下的脚步声
  - 悲伤 → 她把筷子摆得整整齐齐，又把那双没人用的也摆了上去
- 情绪词只允许出现在对话里（人可以嘴上说"我很难过"）
- 品质/能力不直接断言（"他很强"→用旁人反应和事实展示）
- 脚本会抓"感到/非常+情绪词"并警告，语义兜底靠本条

## 📱 网文排版（v6.1，脚本硬卡）

- **单段≤160字**（文字墙=硬伤），段落=手机端1-3行
- **单句成段≥3处/章**：关键句独立成段制造重音（打脸台词/反转句/宣言）
- 对话独立成段，禁止对话和动作挤成大段
- 转折/新场景用空行分场

## 🧱 场景单元结构 + 落差公式（v6.1 落地定义）

**每个场景 = 目标 → 阻碍 → 转折：** 视角人物在这个场景想要什么（目标）→ 什么拦住了（阻碍）→ 结果≠预期（转折）。场景纲按此三字段写。

**落差公式（D02/D04 的核心工具）：**
- 制造冲突：先抬预期，再砸落差——"他以为稳了"→反转
- 制造爽感：先压低主角，再抬升兑现——"被踩到泥里"→当众翻盘
- 三步套用：抬预期（或压主角）→ 砸落差（或抬升）→ 兑现情绪，**落点必须是动作或对话**

## 🎯 写章节执行流程

### 第零步：环境与小说库
- 确认项目目录存在，读取 `templates/项目模板.md` 约定的全部文件
- 配置了百万小说库则检索同类分析写法；未配置跳过，不阻塞

### 第一步：状态校验
- 读取 mind/ 全部6档案 + 上章结尾500字
- 明确本章信息差三层（读者/主角/配角知情范围）
- 确认角色位置/物品/数值/时间与上章一致

### 第二步：事业部调度（每项都必须留下可见动作，禁止扫一眼就过）
- D01设定：列出本章涉及的三根高压线，正文不触碰
- D02剧情：标明本章在卷战役中的位置；用**落差公式**设计主冲突
- D03角色：每个出场角色兑现口头禅/怪癖至少1次（有台词者）
- D04冲突：明确双方诉求 + 谁付代价 + 付什么代价
- D05伏笔：按章纲埋/收伏笔，写完更新追踪表编号
- D06对话：删掉对话前后>30字的动作/心理块；标出潜台词句
- D07描写：本章≥3感（视/听/触/嗅/味），感官落在动作里不单独成段
- D08节奏：≥1处快（短句连发）+ ≥1处慢（长句舒缓）
- D09情感：悲伤场景禁"他很痛苦"，用行为展示
- D10风格：比喻落在动词名词（"刀像活物咬进骨头"），禁"像…一样"堆砌
- D11修辞：本章≥3种修辞（比喻/拟人/夸张/反问等），排比≤2连

### 第三步：四层瀑布
- L1种子：本章核心情绪/信息（1句话）
- L2架构：2-4个场景，按**目标→阻碍→转折**写每个场景的冲突点和情绪转折
- L3叙事：确定视角与时序（默认单主角限知）
- L4渲染：按三段式执行写作（真人策略+比喻打击+反啰嗦+活人感）

### 第四步：26项校验
- **先跑脚本（12项机械），绿了再做AI语义14项；任何一项不过→改→重验**

## 📛 书名与简介（`生成书名简介`）

**书名四式**（≤12字优先，一次给10个候选并标注式别）：
1. 反差式：《捡个小娇夫是千年尸》《四岁冥灵：我靠遗愿欠条成团宠》
2. 金手指直给式：《签到十年，我无敌了》
3. 悬念式：《那晚给我守灵的人不是我爸》
4. 情绪共鸣式：《重生后我把亏欠女儿的还回来》

**简介公式（80-150字）：**
1. 第一句：身份反差（"我是全宗门最废的杂役，直到捡到了师祖的剑"）
2. 第二句：金手指/核心冲突
3. 第三句：钩子断言或问句
- 禁：剧透结局、世界观术语堆砌、"且看…"套话

## 📊 爽点黄金节奏

- **小爽点**：每1-3章一个（赚第一笔钱、打脸小喽啰、得小宝物）
- **中爽点**：每10-20章一个（打败小boss、完成重要任务、获得大提升）
- **大爽点**：每一卷一个（打败最终boss、实现人生逆袭）
- **压抑期：爽点 = 3:1 到 5:1**，没有压抑的爽点像白开水
- **核心原则**：爽点之前必须有铺垫，先让读者憋屈再爆发，爽感翻倍
- **v6.1 补充**：压抑期靠期待线撑翻页率——爽点可以不来，期待线不能断

## 💥 10个爽点公式（可直接套用）

1. **先抑后扬**：先让主角被看不起，再用实力打脸
2. **对比衬托**：用配角的愚蠢衬托主角的厉害
3. **预期违背**：读者以为会这样，结果完全相反
4. **扮猪吃虎**：主角隐藏实力装弱，关键时刻爆发
5. **意外收获**：解决麻烦时意外得到意想不到的好处
6. **复仇打脸**：报复曾经欺负过自己的人
7. **英雄救美/救场**：别人最危险时挺身而出
8. **装逼成功**：在众人面前展示实力收获崇拜
9. **反杀逆袭**：被逼到绝境然后绝地反杀
10. **众人追捧**：从底层变成所有人尊敬的大佬

## 🔗 三种百试百灵的章末断点

1. **悬念断点**：结尾抛出读者猜不到答案的问题
   - 例：主角打开密室的门，里面坐着一个人说："我等了你二十年"
2. **反转断点**：结尾推翻读者之前的认知
   - 例：前面说师父是普通人只会养花→结尾敌人杀到→师父："三百年了，终于有人敢来找我报仇了"
3. **情绪断点**：制造强烈情绪让读者"憋得慌"
   - 例：主角刚救下的人转头把主角出卖了，那人笑着说："你的命比我的良心值钱"

## 🎯 好情节万能公式

**好情节 = 有冲突的事件 + 爽点的结果**
- 外部冲突：主角和反派/配角/环境/命运的矛盾
- 内部冲突：主角内心的挣扎和矛盾（深度的关键）
- 两者必须结合才有深度
- **v6.1 落地**：任何情节拆到场景级执行时，按「目标→阻碍→转折」单元结构推进

## 🔴 番茄爆款铁律

- **快**：开篇300字内必须出冲突，每500-800字一个爽点，没有资格慢热
- **爽**：主角被欺负马上打脸，不憋屈，爽点间隔不超过3章
- **贴**：选题贴合当下热点（赘婿/种田/都市/穿书/悬疑/甜宠）
- **三线并行**：剧情主线+成长线+感情线，感情线不抢主线风头
- **先定高潮结局再倒推**：打破顺写思路
- **单元剧结构**：长篇拆成10万字小战役，每个战役有独立冲突和高潮
- **平台适配**：默认番茄标准；用户指定起点/七猫等时，相应调整开篇容量与卷结构，不编造平台数据

## 🎭 人物描写铁律

- 每次人物出场，**最多描写2个特征**
- 只写**对剧情有用的特征**，**外貌描写不超过30字**
- 不要写环境烘托人物
- **人物靠行为塑造，不靠外貌堆砌**。一个人做了什么比他长什么样重要一百倍

## 🧬 活人感写作

- 至少3处长短句混搭（不能全是差不多长的句子）
- 至少2处插入式思考/犹豫
- 至少1处角色偏好词/口头禅
- 对话必须有潜台词、有省略、有口头禅
- **对话中必须有**：重复用词（口头禅）、打断（"等等！""慢着！"）、说错改口（"不是...我的意思是..."）至少1种
- **禁止对话完美对称**：不要A说一行B说一行机械交替，有的人只说3个字，有的人连续说三句
