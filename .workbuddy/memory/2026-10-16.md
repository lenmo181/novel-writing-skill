- 命令：`python skills_store_cli.py login --key skh_xxx --host https://api.skillhub.cn` → `auth whoami` → `publish <dir> --changelog "..." --host https://api.skillhub.cn`。

**三个真实踩坑（下版必须记牢）**：
1. **frontmatter 字段名对不上**：CLI 必填 `slug`(kebab-case 2-128) / `version`(SemVer) / `displayName`（**驼峰**），而构建包内是 `name` / `display_name`（下划线）。→ 解法：发布前把 SKILL.md 补上 `slug` + `displayName`（+ summary/license），`name`/`description` 保留给 WorkBuddy 用，两者可共存。
2. **服务端文件类型白名单**：包内无扩展名文件被拒 → `400 不允许的文件类型: LICENSE`（NOTICE 同理）。→ 解法：发布目录移除 `LICENSE`/`NOTICE`（许可证改由 frontmatter `license: MIT` 声明）。`.ps1` 服务端接受。
3. **API Token 生成**：`/dashboard/keys` 点「创建 API key」→ 填名 → 创建后令牌只显示一次；**用弹窗里的「复制 Token」按钮把令牌送剪贴板，再 PowerShell `Get-Clipboard` 读出**（DOM 快照不含令牌明文）。浏览器自动化点这个按钮有效（不同于 gitee 令牌页的反自动化拦截）。

**发布时必须避开的老路**：网页上传表单的「选择 zip 文件」是**系统原生文件框**，浏览器自动化无法操作；剪贴板粘贴文件、PowerShell COM/Add-Type 发键全被沙箱拦截 → 不要在这条路上耗时间，直接走 CLI。
