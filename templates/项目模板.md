# 项目初始化模板

> 初始化项目时，AI 必须按本模板在项目目录下创建全部文件，不得凭记忆即兴生成结构。
> 用户提供了设定就填入；没提供的部分由 AI 生成草稿，经用户确认后写入。

## 项目目录结构

在项目根（默认 `C:\Users\lenmo\.zcode\workspace\novels\`，可配置，见 SKILL.md 全局配置表）下建 `<书名>\` 目录，并在其中创建：

```
《书名》/
├── 书稿/
│   └── 第001章_章节名.md      # 每章一个文件，纯正文+章节标题行
├── 大纲/
│   ├── 总纲.md                # 一级：核心创意+高潮结局倒推
│   ├── 卷纲.md                # 二级：每卷=10万字小战役
│   ├── 章纲.md                # 三级：每章核心事件
│   └── 场景纲.md              # 四级：每章内场景清单（目标→阻碍→转折）
├── 设定/
│   ├── 世界观.md
│   ├── 角色.md
│   ├── 金手指.md              # 无能力体系则删；按四原则写：有门槛/有代价/可成长/可视化
│   └── 文风样本.md            # v7.4 软门禁：可由用户直供，或复用拆文的 文风.md（无样本不阻塞）
├── 封面/                      # 封面_vN.png + .prompt.txt（生成时创建）
├── .story-review/
│   └── state.md               # 整卷审查断点（开放项继承，见 references/审校.md）
└── mind/                      # 档案区，AI 每章写完自动更新（七档案 + 回顾/）
    ├── 角色状态快照.md         # 含"知情"字段（信息差三层管理）
    ├── 锚点日志.md
    ├── 伏笔追踪表.md
    ├── 时间线.md
    ├── 章节目录.md             # 兼进度表；摘要行含脚本AI味指数
    ├── 剧情走向锁定.md
    ├── 作者记忆.md             # 作者偏好四类记录+回执（见SKILL.md作者记忆系统）
    └── 回顾/                   # 叙事因果层（v7.3，见 references/连载记忆.md）
        ├── 第001章回顾.md …    # 微型单章回顾，每章一份（150-300字六栏）
        └── 阶段回顾_第X-Y章.md # 每5-15章合并一份（十节结构）

# 拆解产物统一放 <项目根>\拆文库\{书名}\（不放进单书目录，见 references/拆文.md）
```

## 四级大纲定义

| 级别 | 文件 | 粒度 | 必含字段 |
|------|------|------|---------|
| 一级·总纲 | 总纲.md | 全书一句话 + 结局 | 核心创意、高潮场面、结局、主角终点状态 |
| 二级·卷纲 | 卷纲.md | 每卷（约10万字） | 卷名、本卷大冲突、大爽点、卷末钩子、进出场角色 |
| 三级·章纲 | 章纲.md | 每章一条 | 章号、核心事件、冲突双方、爽点类型、埋/收伏笔编号、**节奏类型**、章末钩子类型（兼记钩子语义指纹）、冲突值（可选列，由 `tools/conflict_score.py` 生成） |
| 四级·场景纲 | 场景纲.md | 每章2-4个场景 | 场景地点、在场角色、冲突点、情绪转折 |

**章纲表头（v7.4，可直接复制）**：

| 章号 | 核心事件 | 冲突双方 | 爽点类型 | 埋/收伏笔编号 | 节奏类型 | 章末钩子类型（兼钩子指纹） | 冲突值(可选) |
|------|---------|---------|---------|--------------|---------|--------------------------|-------------|

- **节奏类型**取值（枚举白名单，不得自造）：主线 / 峰值 / 缓冲-对话 / 缓冲-线索 / 缓冲-代价 / 校准（细则见 `references/节奏与结构.md`）
- **钩子指纹**形如 `主角-发现-密信`（载体-动作-对象），与该章末钩子的语义一一对应

## 设定模板（用户发设定时按此解析）

【世界观】：时代/地点/规则体系/三根高压线（绝不可违背的设定，违反即吃书）
【主角】：姓名、性格、能力、口头禅、怪癖、缺陷（必须有缺陷，完美人设禁用）
【关系方程式】：每个重要角色与主角的关系模式及变化方向（**保持定性**：关系模式 + 变化方向，如"师徒→戒备，方向：渐生猜疑"；好感度/信任度等**数值化写法标为可选**，用户明确要求时才用，不作为默认字段）
【大纲】：按四级大纲填写，至少到每章发生什么

## mind/ 档案格式（七档案 + 回顾/）

> 口径：`mind/` 下固定 **7 个档案文件**（角色状态快照 / 锚点日志 / 伏笔追踪表 / 时间线 / 章节目录 / 剧情走向锁定 / 作者记忆）+ **`回顾/` 目录**（单章微型回顾 + 阶段回顾）。凡提"mind 档案"一律 = 七档案 + 回顾/，不得另说 6/8。

### 角色状态快照.md
每角色一条，每章更新（本章新出场实体也登记在此，**不另建实体台账**）：
```
## 角色名
- 别名：正文中出现过的其他称呼（顿号分隔，无则写"无"）
- 首次出场章：第X章
- 位置：当前所在地点
- 持有：重要物品清单
- 状态：伤势/修为/金钱等关键数值
- 情绪：当前情绪及成因
- 知情：知道哪些关键信息（信息差管理用）
- 最后出场：第X章
```

### 锚点日志.md
按章追加：`第X章 | 锚点类型（人物/物件/承诺/约定/死亡） | 内容 | 涉及角色`

### 伏笔追踪表.md（v7.4 六列）
| 编号 | 伏笔内容 | 埋设章 | 预计回收章 | Tier | 状态（未回收/已回收/已废弃） |

- **Tier** 取值：`T1`（战略级，与主线/结局相关）/ `T2`（战役级，本卷内）/ `T3`（战术级，近场数章内）
- 沉睡阈值：T3 15-20 章 / T2 30-40 章 / T1 卷末审计（见 `references/常量表.md`）

### 时间线.md
按章追加：`第X章 | 故事内时间（X月X日/时段） | 跨度说明`

### 章节目录.md（兼进度表，一键生成据此断点续写）
| 章号 | 标题 | 字数 | 节奏类型 | 校验结果 | 完成日期 |

- 本表由 `tools/gen_index.py` 从 `书稿/` 扫描生成：**读旧表 → 按章号合并 → 只补缺省行**，已有的「校验结果 / 完成日期」不会被覆盖
- 节奏类型列可由章纲回填；需要时可在表尾追加「冲突值」可选列（由 `tools/conflict_score.py` 生成）

末行固定写：`当前进度：已完成至第X章，下一章为第X+1章`

### 剧情走向锁定.md
追加式记录已定死的剧情决策：`日期 | 决策内容 | 来源（用户指定/正文已写死）`

### 作者记忆.md
四类记录，逐条一行，格式固定（细则见 SKILL.md「作者记忆系统」）：
```
- [一次性要求] 日期 | 内容 | 处理：只执行不记录（例：这章别写雨戏）
- [小说事实]   日期 | 内容 | 已并入：设定/角色.md#某某
- [推断偏好]   日期 | 内容 | 状态：待确认（复现 N 次转正）
- [显式覆盖]   日期 | 内容 | replace：《被覆盖的旧记录原文》 | 冲突标注：旧记录保留于下行
- [旧记录·已废止] 日期 | 内容（被上方 replace 覆盖，保留供查史）
```
- **replace 冲突标注格式**：新记录必须写 `replace：<旧记录原文>`，并在紧随其后保留一行 `[旧记录·已废止] …`（带原日期），**不许直接删改旧行**。
- 回执：用户说"记住：XXX"→ 执行后必须输出 `✅ 已记住（类型：XX）`。

### mind/回顾/第XXX章回顾.md（v7.3 单章微型回顾，六栏固定）
```
## 第XXX章回顾
- 一句话：（≤50字，起因+结果+悬念）
- 关键事件：3-6条（冲突+行动+结果，按时间序）
- 状态与关系变化：只写有变化的（从什么变成什么）
- 信息差变动：谁新知道什么 / 谁仍不知道 / 谁产生误解
- 伏笔变动：新增（编号）/ 推进（编号）/ 回收（编号）
- 下章承接：结尾场景、未了结冲突、必须延续的状态
```
阶段回顾_第X-Y章.md 为十节结构（融合原则/信息差矩阵/伏笔生命周期/续写硬约束等），格式见 `references/连载记忆.md`。

## 设定/文风样本.md（v7.4 软门禁骨架）

> 有样本 → 写作以样本文气为基准；无样本 → **不阻塞写作**，按现有 8 Gate 反 AI 基线继续，写完提示一次"建议补文风样本以提高贴合度"。
> 可由用户直供，也可直接复用 `拆文` 产出的 `文风.md`（同一字段集，**不建平行体系**）。

```
# 文风样本

## 风格定位
（一句话：冷硬口语 / 细腻书面 / 轻快吐槽 …… 附对标作品名与平台调性）

## 样本文本
（粘贴 300-800 字最能代表目标文气的原文段落；只作本项目内私有参考）

## 风格基因
- 句长配比：（短句为主/长短交替/长句舒缓）
- 标点习惯：（少用省略号/爱用破折号/独句成段频率）
- 对话特征：（口语化程度、潜台词密度、提示语用法）
- 心理描写：（内心独白多/靠行为暴露）
- 感官侧重：（视/听/触/嗅/味 的配比）

## 反例黑名单
（本作明确不用的写法：如"仿佛/似乎"式模糊虚词、空泛环境描写、
  四字成语堆砌、AI式意象（空气凝固/时间静止）……逐条列出，写作时硬禁）
```

**版权提示**：样本仅作**项目内私有参考**；不得逐句抄写、不得入库分发；样本为外部来源时版权风险由用户自担。本技能**不导入任何上游题材包**。

## .story-review/state.md（整卷审校断点，字段定义）

> 用途：整卷/多章审查分批进行时，继承上一批的开放项，避免盲目全量重跑。路径固定为**项目根下 `.story-review/state.md`**（不进 mind/，属审校工作区）。

```
# 审查断点状态

- 审查范围：第X-Y章
- 审查日期：YYYY-MM-DD
- 本批已处置：S1 0 项 / S2 3 项 / S3 5 项 / S4 2 项

## 开放项
| 编号 | 级别 | 类别 | 位置 | 问题 | 处置状态（待办/已修/搁置） |
|------|------|------|------|------|--------------------------|

## 继承的伏笔开放项
（已埋未收的伏笔编号 + Tier + 预计回收章）

## 下批起点
- 下一批审查从第X章开始
- 需重点复查：<本批搁置项>
```
