# 网络小说创作技能

> 当前版本：**v6.1**（2026-09-12） · 历史版本见 [`versions/`](versions/)

面向 ZCode / AI 编码助手的网文创作主力技能：把"会写小说"变成**可验证的工程流程**——机械校验脚本硬卡，不过不许交付。

## 核心能力

- **26项校验**：脚本硬卡12项（字数2500-3000 / 对话占比≥40% / A级禁言词 / AI套话库 / 文字墙 / 引号规范 / 格式残留…）+ AI语义14项（人设 / 逻辑 / 伏笔 / 视角纪律 / Show don't tell…）
- **写作手艺**：黄金开篇（前三章任务表+8条禁开头）、期待感体系（打脸预告/身份悬念/目标牵引/危机倒计时+信息差三层管理）、场景单元结构（目标→阻碍→转折）、落差公式
- **工程化**：项目模板落地、mind/ 档案6文件自动更新、一键生成断点恢复、标准审稿卡（五维25分制）
- **反AI防线**：禁言词库（A/B级）、AI套话库36词、反AI啰嗦8条、活人感规则

## 目录结构

```
├── SKILL.md                 # 技能主文件（版本号在这里）
├── templates/项目模板.md     # 初始化项目强制模板
├── tools/check_chapter.py   # 机械校验脚本（纯标准库 Python 3.10+）
└── versions/                # 历史版本完整存档
```

## 用法

ZCode 用户：放到 `~/.zcode/skills/网络小说创作技能/`，对 AI 说"初始化项目"即可。

章节校验：

```bash
python tools/check_chapter.py "书稿/第001章_章节名.md"
# 退出码 0=通过 / 1=有硬伤禁止交付；--min/--max 可调整字数区间
```
